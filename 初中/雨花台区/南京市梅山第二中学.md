## 二、基本情况

### 2.1 学校定位

梅山第二中学是**雨花台区梅山片区的公办初中**，地处南京市雨花台区**「雨核」区域**、坐拥**新秦淮河**。它的独特之处在于：**并非从南京本地教育系统生长而出，而是由上海宝钢梅山铁矿的企业办学体系转制而来**——这使它的历史脉络、文化气质与南京本土公办校明显不同。`[A]`

学校现隶属**南京市梅山总校**（划归雨花台区教育局管理），与同片区的**梅山第一中学（初中）**、**梅山高级中学（高中）** 共同构成梅山片区的完整教育链条。`[A]`

### 2.2 历史沿革（五十年的「三迁校址、两易身份」）`[A]`

学校公开的五十周年校史资料，完整呈现了其**从企业子弟校到南京公办校**的百年脉络（合并自「梅山二中简介」与「五十周年校史资料征集公告」）：

| 时间 | 里程碑 |
|---|---|
| **1976** | 前身「**梅山工程指挥部铁矿职工子弟中学**」在**梅山铁矿吴家山口**建校，肩负为宝钢梅山矿区培养人才的重任 |
| 1980 | 升格为**完全中学**，更名「**上海梅山第二中学**」 |
| 1984 | 整体迁址**梅山铁矿兴梅中路**新校区 |
| 2000 | 梅山矿业公司斥巨资，学校整体搬迁至**梅山铁矿寺门口校区**，硬件全面提质 |
| 2003 | 梅山地区教育资源整合，**初中部回迁梅山铁矿兴梅中路校区**，建成现在的梅山二中 |
| **2008** | 按照中央政策，学校**正式划归南京市雨花台区**管辖，更名「**南京市梅山第二中学**」，深度融入南京教育体系 |
| **2021.09** | 学校**启用江苏本地教材，面向南京区域招生** |
| 2024 | **2024 届毕业生首次参加南京中考** |
| **2026** | 迎来**建校五十周年**校庆，举办第 43 届秋季田径运动会 |

> **解读**：梅山二中是一所**「企业办学转型」样本**。2008 年划归南京、2021 年换用江苏教材——**真正「南京化」只有十余年、完整按南京中考体系办学仅数年**。这既造成其**南京成绩积淀较浅**，也意味着它正处在**「江苏化 / 南京化」的适应上升期**。`[B]`

### 2.5 「对口小学」问题的说明

雨花台区公办初中**按地理边界 / 社区划片**，**不采用「初中—对口小学」一一对应制**，因此**不存在官方公布的「对口小学」名单**。

梅山二中的入学对象为**施教区内（梅山街道矿区部分：梅欣、梅岭社区）的应届小学毕业生**。家长通常按社区归属判断就读学校。`[A]`

## 四、招生入学

### 4.1 招生方式：施教区免试就近入学（主要途径）`[A]`

- 应届小学毕业生应具有学校**施教区户口**；
- 户口原则上应与父母（或法定监护人）**同一户籍**；
- 户籍与实际常住地、房屋所有权证（持有者为法定监护人）**一致**；
- 学校**严格遵守免试入学**规定：不通过文化课考试 / 测试招生，不收取学生个人简历或视频音频等展示材料，**不以学科竞赛、考试证书、荣誉证书、培训证明等作为录取依据**。

### 4.2 特殊情形入学条件 `[A]`

| 情形 | 规定 |
|---|---|
| 户籍随一方监护人 | 另一方为不在本市工作的现役军人 / 在外地工作 / 务农 / 出国定居的 |
| 父母离异 | 毕业生户籍随法定监护人在施教区且实际长期居住 |
| 双方均在外（军人 / 公派） | 子女户口单立或随祖父母（外祖父母）在施教区常住 |
| 祖辈房产 | 毕业生自出生起即随父母户口在祖父母（外祖父母）处落户，父母双方无独立房产、实际常住且户口从未迁移 |
| 拆迁户（未购 / 未安置） | 在原施教区中学报名 |
| 拆迁户（已安置） | 凭材料在安置房所属施教区中学报名 |
| 拆迁户（已购新房） | 须在报名前将孩子及监护人户口迁至产权房处，在新购房施教区报名 |
| 其他特殊情况 | 由区教育局统筹安排入学 |

### 4.3 「长幼随学」（2026 年新增）`[A]`

自 **2026 年秋季学期起**，对就读本区初一年级有「**幼随长**」需求的新生，**试行「长幼随学」**——符合本区入学条件的家庭可向学校申请，经审核后**根据学位情况**予以相应安排。

> **解读**：方便多孩家庭把弟弟妹妹安排到与哥哥姐姐同一所学校，**降低接送成本**。梅山二中与南站中学等为 2026 年明确试行该政策的学校。

> 「**2024 届毕业生首次参加南京中考，便取得骄人成绩**，魏语涵、陈杰文、郑雅婷等 **70% 以上同学被南师附中、金陵中学、第二十九中学等高中录取**。」`[B]`

**2025 届**：「中考续写辉煌，江南、陈诺、张文臣等一大批学子圆梦南京市头部高中或全市其他四星级名校。」`[B]`

> ⚠️ **信度提示（重要）**：上述「**70% 以上同学被南师附中、金陵中学、第二十九中学等高中录取**」为**学校招生宣传口径**，**存在表述夸张的可能**。
>
> - 若按字面理解，意味着该校 70% 以上毕业生进入**全市最顶尖的三所高中**——这对一所规模仅 500 人、2024 年才首次参加南京中考的学校而言，**几无可能**。
> - 更合理的解读是：**「70% 以上达到（含四星 / 优质）高中线，其中部分学生进入南师附中、金中、二十九中等校」**；或该比例针对**足球特长队员等特定群体**。
> - 本档案**如实呈现原文，并提示其为宣传口径，读者应谨慎理解**。

### 6.2 「首次南京中考」的特殊性

> **关键背景**：梅山二中**2021 年 9 月起才启用江苏教材面向南京招生**，**2024 届是第一批完整按南京中考体系培养并参考的毕业生**。因此：
> - 该校的**南京中考历史极短**（2024、2025、2026 共约三届）；
> - **与南京本土老牌初中做横向对比意义有限**，更应关注其**「南京化」后的成长趋势**；
> - 学校**连续多年荣获雨花台区中考质量优秀奖**（学校口径）。`[B]`

## 十、择校小结

### 适合的学生画像

| 维度 | 判断 |
|---|---|

| 追求小规模、高关注度 | ★★★★★（在校生约 500 人） |
| 追求公办零学费、低成本 | ★★★★★ |

| 需要方便的主城通勤 | ★★☆☆☆（位置偏西南） |

### 关键决策变量

1. **「年轻 vs 老校」的错位是第一变量**：梅山二中是「**五十周年老校，但南京中考经验仅数年**」的错位体。它 1976 年创办、2026 年五十周年校庆，历史不短；但**2021 年才换用江苏教材、2024 年才首次参加南京中考**——**真正「按南京体系出成绩」的历史极短**。适合**看重特色、就近、低成本**的家庭，不适合**单纯冲南京顶尖高分**的需求。
2. **足球（女足）是最确定的「升学抓手」**：**女足**是梅山二中最具辨识度、成果最可核的通道——**历届足球队员 100% 考取四星级高中**，2024 届女足队长被南师附中录取，且 **2026 年 4 月获批区级初中体育特定类型（女足）招生资格**。有足球特长的学生，这是**性价比极高的确定性路径**。
3. **施教区严格限定「梅山街道矿区部分」**：仅覆盖**梅欣社区、梅岭社区（含梅苑小区）**。与**梅山第一中学（梅山街道生活区）** 形成明确二分。**入学前务必确认社区归属**。
4. **整体升学数据需谨慎**：学校「70% 以上被南师附中 / 金中 / 二十九中录取」为**宣传口径、存在夸张可能**；**官方量化数据缺失**。建议家长**直接到校咨询**（电话 56322266），要求提供近年**四星率 / 普高率的官方口径**。
5. **「企业子弟校」的社区属性**：学校根植于**梅山矿区企业社区**，生源与社区高度绑定，**文化认同感强、外部辐射有限**。这对**本社区家庭**是「归属感 + 便利」的优势，对**社区外家庭**则是「陌生 + 通勤远」的门槛。
