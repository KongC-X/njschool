# 南京市第九中学教育集团中桥中学

> **一句话定位**：八卦洲上**唯一一所公办初中**，1956 年建校、与南京市第九中学有「下放办学十年」的特殊渊源，2023 年正式冠名「南京市第九中学教育集团中桥中学」；以「**积跬行健**」为办学理念，拥有 16 亩「恪勤园」劳动实践基地与江苏省「乡村现代农业」劳动课程基地，是**全国首批校园足球特色学校**、**江苏省示范初中**。

## 二、基本情况

### 2.1 学校定位：一座江岛上的「独苗」初中

中桥中学的特殊性，一句话就能说清：**它是八卦洲上唯一一所初级中学**。`[A]`

八卦洲是长江中的冲积沙洲，与江南主城、江北新区均隔江相望，交通依赖轮渡与跨江桥梁。这种地理封闭性，塑造了中桥中学几乎全部的特征：

| 地理特征 | 教育后果 |
|---|---|
| 江岛封闭，人口外流 | 生源逐年减少，2009 年两校合并后成为全洲唯一初中 |
| 与主城隔江 | 优质师资引进难，教师队伍本地化程度高 |
| 农业为主，田园资源丰富 | 劳动教育、生态教育有天然优势 |
| 社区熟人社会 | 家校关系紧密，学校承担较强的社区功能 |
| 交通改善（跨江通道） | 年轻家庭外迁与回流并存，生源结构变动 |

学校自述其使命时用了一句话：「脚踏实地，砥砺前行，自强不息，**延续洲上先民拓荒和苦干精神**，为社会培育身心俱全一步一个脚印走正道、行大道的行健少年。」`[A]`

> **解读**：「拓荒和苦干」是沙洲移民的历史性格，学校把这套地方精神提炼为「**积跬行健**」——积跬步以至千里，行健而不息。这套话语不是凭空造的，它有真实的地理与人群基础。对一所生源有限、资源有限的江岛初中，这种「不与人比快、只与人比久」的定位，是清醒且务实的选择。

### 2.2 七十年的六次身份变更 `[A]`

中桥中学的校史，几乎就是八卦洲基础教育布局调整史。学校在 2023 年征稿启事中完整梳理了这条线索：

| 时间 | 事件 |
|---|---|
| **1956 年 8 月** | 建校，校名「南京市八卦洲初级中学」，创办时仅**初一 2 个班、教师 4 名**，原址在八卦洲青年桥附近 |
| **1968 年** | 南京市第九中学**全校师生下放至八卦洲**办学 |
| **1970 年 3 月** | 九中 + 八卦洲上坝农中 + 八卦洲初级中学**三校合并**为「南京市八卦洲中学」，成为一所**完全中学**，并分置中桥、上坝、新闸三个办学点 |
| **1978 年** | 九中教师陆续返城，三个办学点开始独立办学；中桥是三所中唯一保留**完中**（初中+高中）的 |
| **1979 年 4 月** | 布局调整，上坝中学、新闸中学划出独立；原八卦洲中学更名「**南京市八卦洲中桥中学**」 |
| **1992 年** | 高中部停止招生，**职业高中**应运而生 |
| **1996 年** | 上坝中学拆并入中桥和新闸 |
| **2002 年** | 职高停止招生 |
| **2009 年 7 月** | **新闸中学并入中桥**，「南京市八卦洲中桥中学」至此确定为洲上唯一一所初级中学，直属栖霞区教育局 |
| **2023 年** | 与南京市第九中学签约合作办学，冠名「**南京市第九中学教育集团中桥中学**」 |

> **解读**：这条时间线里有两个关键节点。
>
> **第一个是 1968—1978 年。** 南京市第九中学整体下放到八卦洲办学，校址正是今天的中桥中学校园。这十年不是一般的「帮扶」，而是**一所城市名校整建制地在江岛上生活了十年**。九中的教师在这里上课、生活、与本地人通婚，两校的文化基因由此真正混在一起。2026 年 2 月，九中教育集团把年度研讨会放在中桥中学召开，主题是「人工智能背景下学校教学改革的策略与途径」，杨静芳校长在致辞中专门回顾这段渊源——**这不是客套，是有实物、有老人、有记忆的历史资产**。`[A]`
>
> **第二个是 2009 年。** 新闸中学并入后，中桥成为全洲唯一初中。这意味着**它没有竞争对手，也没有替代选项**：岛上孩子要读公办初中，只能来这里。这既是垄断性的稳定，也是缺乏外部压力的隐忧。

### 2.3 施教区（2026 年官方公布）`[A]`

据《南京市栖霞区2026年公办初中一年级招生施教区范围》：

> **施教区范围**：八卦洲街道所辖区域。

| 维度 | 说明 | 信度 |
|---|---|---|
| 表述形式 | 「八卦洲街道**所辖区域**」——整街道全覆盖，无排除项 | A |
| 覆盖范围 | 八卦洲全岛（含中桥、新闸、上坝、外沙、七里、光明、东江等村社） | A |
| 唯一性 | 全洲**仅此一所**公办初中，无第二选择 | A |
| 与小学衔接 | 八卦洲中心小学（含各办学点）毕业生整体对口本校 | C |

> **解读**：这是本档案六所学校里**唯一一个「整街道无切分」**的施教区表述。没有「不含某某校施教区」的排除语，也没有「仅某某社区」的限定语——因为岛上只有这一所初中，不需要切分。
>
> 对家长的实际意义：**八卦洲户籍的小学毕业生，不存在「派到别的初中」的可能**。选择空间为零，也因此不需要研究划片边界。真正需要研究的是：**要不要为了更好的初中而迁出岛**。

### 2.4 校园与环境 `[A]`

学校自述的校园条件（2023 年征稿启事原文）：

> 「我校占地 22847 平米，另有**劳动教育基地约 16 亩**，建有**四幢教学楼**。花圃、林竹、草地、池塘、假山、亭榭，错落有致，为**南京市首批园林校园**。配备有**体育馆、食堂、网球场、标准足球场**及绘画、音乐、舞蹈、电子等各种功能教室。」`[A]`

| 设施 | 说明 |
|---|---|
| 教学楼 | 4 幢 |
| 运动设施 | 体育馆、标准足球场、网球场、篮球场（旧志记 250 米环形跑道、篮球场 2 块） |
| 功能教室 | 绘画、音乐、舞蹈、电子等 |
| 实验室 | 物理、化学、生物、数字化实验室各 1 个（旧志） |
| 图书与报告厅 | 图书馆、教师/学生阅览室、多媒体报告厅 |
| 景观 | 花圃、林竹、草地、池塘、假山、亭榭 |
| 园林认定 | **南京市首批园林校园** |

> **解读**：一所 10 个班、376 名学生的江岛初中，拥有**体育馆 + 标准足球场 + 网球场 + 16 亩劳动基地 + 四幢教学楼**。按生均计算，其体育与劳动空间的宽裕程度，超过绝大多数城区初中。这是「小规模 + 大面积」的结构性红利，也是学校能把劳动教育做成省级课程基地的物理前提。

### 3.1 班级规模

| 指标 | 数据 | 信度 | 年份 |
|---|---|---|---|
| 教学班 | **10 个** | B | 约 2026 |
| 在校学生 | **376 人** | B | 约 2026 |
| 教职工 | **65 人** | B | 约 2026 |
| 历史峰值 | 16 个班、774 名学生、90 名教职工 | C | 约 2000 年代 |
| 2026 级新初一班级数 | **未获取** | — | — |

**规模变化对比：**

| 指标 | 历史峰值 | 当前 | 变化 |
|---|---|---|---|
| 班级数 | 16 个 | 10 个 | −37.5% |
| 学生数 | 774 人 | 376 人 | −51.4% |
| 教职工 | 90 人 | 65 人 | −27.8% |

> **解读**：学生数腰斩、教师数只减四分之一，直接结果是**师生比大幅优化**。按 65 名教职工、376 名学生计算，师生比约 **1:5.8**；即便只算专任教师，也远优于城区大校。这意味着**每个学生能获得的教师注意力显著更高**——这是小规模江岛校最实在的优势。
>
> 但硬币的另一面是：**10 个班、每年级约 3—4 轨**。同伴群体规模小，意味着社团、选修、竞赛梯队的组建都很困难；一个年级 120 人左右，能组成的「学霸圈」非常有限。对学业拔尖的孩子，这是真实的天花板。

### 3.2 分班与评价机制 `[A]`

| 机制 | 内容 |
|---|---|
| 均衡分班 | 按南京市统一要求，严禁重点班、快慢班；2026 年教育部要求方案、过程、结果三公开 |
| **「行健积分」** | 学生综合表现积分体系，作为评优依据 |
| **「行健少年」** | 每学期评选七、八、九年级「行健少年」，依据上学期行健积分与综合素质表现综合评定 |

> **解读**：「行健积分」是一套**过程性评价**工具，而非终结性考试排名。它把品德、劳动、活动参与、日常表现折算成可累积的分值，再据此评选「行健少年」。对生源基础一般的学校，这种设计有明确的教育意图：**让不擅长考试的孩子也有被表彰的通道**。这与学校「积跬行健」的理念是一致的——重视持续的小进步，而非一次性的高分。

## 五、升学政策

### 5.1 指标生 `[A]`

- 指标生按各初中**具备报考资格的应届毕业生人数**为基数分配。
- **投档控制线**：原市区/浦口区 2026 年为 **593 分**（全市中考排名前 30% 考生最低分）。
- 中桥中学享受指标到校政策；分到本校的具体名额**未获取**。

> **解读**：中桥中学是**指标生政策受益最典型的一类学校**。每年级约 120 人，若指标生名额按比例分配，校内前若干名的学生即可获得四星级高中的指标资格。在一所「没有第二选择」的江岛初中，这条通道对学业中上的孩子具有决定性意义——它意味着**不必迁出岛、不必买学区房，也有机会进入优质高中**。
>
> 这也是近年南京「指标到校」政策持续向薄弱初中倾斜的直接效果。家长在评估这所学校时，应把「指标生名额 ÷ 毕业生人数」作为一个核心指标来问，而不是只看四星率。

### 5.2 中考升学路径总览

| 批次 | 说明 |
|---|---|
| 提前批次 | 指标生、南外校内生、体育/艺术特长生 |
| 第一批次 | 四星级及经批准在此批次招生的普高 |
| 第二批次 | 三星级及以下普高、综合高中班、五年制高职等 |
| 第三批次 | 中专中职、技工学校 |

志愿数量：每人最多 11 个（提前批 2 + 一批次 3 + 二批次 4 + 三批次 2）。`[A]`

### 5.3 体育特长通道

学校为**全国首批校园足球特色学校**，拥有标准足球场与体育馆。`[A]` 足球是该校最成熟的体育项目，为具备足球特长的学生提供了校内训练基础。近年向高一级学校输送足球特长生的具体人数**未获取**。

### 6.2 从校史看「出口质量」

中桥中学的升学叙事，主要建立在**校史纵深**而非近年数据上。学校在征稿启事中写道：

> 「纵观我校的历史，变迁中不乏精彩。僻居一隅，看似默默无闻，其实**人才辈出**。学校已为八卦洲培养了**整整四代人**。」`[A]`

这句话的实际含义是：自 1956 年建校至今 70 年，岛上凡读过初中的家庭，几乎都与中桥有交集。**四代人的校友网络**，是一所江岛学校独有的社会资本——它不体现在分数上，而体现在：本地教师很多是校友、家长对学校有天然信任、学生能看到「读出去」的真实榜样。

> **解读**：这类「历史型」学校的特点是**下限稳定、上限不明**。它不太可能出现大规模滑坡（社区监督强、教师队伍稳定），但也缺少可量化的拔尖证据。对家长而言，判断依据应从「数据」转向「人」：**近三年有没有学生考入四星级高中？去了哪几所？各几人？** 这些绝对数字，在校家长几乎都知道。

### 6.3 劳动教育作为「另一种出口」

中桥中学最独特的办学成果不在中考，而在劳动教育：

| 项目 | 内容 |
|---|---|
| 基地 | 16 亩「恪勤园」劳动实践基地，含**五谷园、野菜园**等主题园区 |
| 课程 | 「**勤·健**」劳动课程 |
| 省级认定 | 2022 年创建**江苏省「乡村现代农业」劳动课程基地** |

### 7.3 办学理念：「积跬行健」`[A]`

| 要素 | 内涵 |
|---|---|
| 积跬 | 出自《劝学》「不积跬步，无以至千里」——重视积累、重视过程 |
| 行健 | 出自《易经》「天行健，君子以自强不息」——重视坚持、重视自我驱动 |
| 合义 | **一步一个脚印走正道、行大道** |
| 学生画像 | 「身心俱全」「行健少年」 |
| 评价载体 | 「行健积分」→「行健少年」评选 |
| 校园话语 | 「行健自强」「积跬致远」（2026 元旦汇演主题：行健自强凌云志，积跬致远启新程） |

> **解读**：这套理念的优点是与生源现实高度匹配——**不要求孩子跑得快，只要求不停下**。对一所没有优质生源筛选权的江岛初中，这是唯一可行的教育哲学。它的风险则在于：**「积跬」容易变成「低预期」的自我合理化**，如果学校把「慢慢来」当成不追求高标准的借口，理念就会退化为安慰剂。判断标准是：学校是否仍在为前 10% 的学生提供足够的挑战。

- ⚠️ **「唯一选择」的副作用**：缺乏校际竞争压力，改进动力依赖外部（区教育局、集团）

## 十、择校小结

### 适合的学生画像

| 维度 | 判断 |
|---|---|
| 八卦洲户籍、家在岛上 | ★★★★★（唯一公办初中，就近入学） |
| 孩子需要高关注度、师生关系紧密 | ★★★★★（师生比约 1:5.8，教师了解每个学生） |
| 目标指标生、校内排名中上 | ★★★★★（规模小，指标生竞争最温和） |
| 对劳动/生态/农业有兴趣 | ★★★★★（省级劳动课程基地，16 亩基地） |
| 有足球特长 | ★★★★☆（全国首批校园足球特色校，标准足球场） |
| 家庭重视安全、不愿孩子跨江通学 | ★★★★★（岛内封闭环境） |
| 追求高升学率与强同伴竞争 | ★★☆☆☆（生源规模限制，缺少同层次竞争） |
| 要求透明量化成绩 | ★☆☆☆☆（官方零披露） |
| 需要丰富课外培训资源 | ★★☆☆☆（岛内资源有限，跨江成本高） |

### 关键决策变量

1. **第一个问题不是「选哪所」，而是「要不要出岛」**——八卦洲只有这一所公办初中，没有第二选项。真正的决策是：留在岛上读中桥，还是举家迁出、或报考民办/南外。这个决策的成本量级远大于校际比较。
2. **指标生是这所学校最大的制度红利**——每年级约 120 人，前若干名即可获四星高中指标资格。如果孩子学业中上，留在岛上「做鸡头」的实际收益，可能高于进城「做凤尾」。建议直接向学校问：**去年指标生名额几人、实际用掉几人**。
3. **小规模的利弊要成对看**——关注度高是优势，同伴竞争弱是代价。若孩子学业拔尖，需确认学校是否有培优机制、是否组织参加区级学科竞赛。
4. **劳动教育不是「副科」**——16 亩基地 + 省级课程基地 + 微型动物园 + 生态心育，这是该校真正的差异化资产。如果家庭认同「身心健全优先于分数」，这条线值得认真评估。
5. **九中集团的支持要看持续性**——「每周深入课堂指导」若持续，三到五年后教学质量会有实质变化；若随集团工作重点转移而弱化，效果会打折。可向在校家长了解近一年集团教师来校的实际频次。
6. **通勤与住宿必须提前确认**——江岛通学距离差异大，校车与住宿安排是本档案未覆盖的关键信息。
