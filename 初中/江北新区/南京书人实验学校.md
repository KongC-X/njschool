## 二、基本情况

### 2.1 学校性质与定位 `[A]`

南京书人实验学校是一所**十二年制民办学校**，涵盖幼儿园、小学、初中，并设有高中部（含国际课程方向）。学校坐落于江北新区（浦口区）浦乌中路 199 号，隶属「书人教育」品牌体系。

> **解读**：书人实验是南京民办教育中**「培训基因 + 全日制办学」**的典型代表。其北侧与江北新区多个公办名校（金陵中学浦口分校、中华中学浦口城南中学等）同处一片教育快速增长的区域。

### 2.2 办学理念与特色简介 `[A]`

| 维度 | 内容 |
|---|---|
| 学段完整度 | 幼儿园 → 小学 → 初中 → 高中（国际课程） |
| 教学机制 | 「六统一 + 三套教学案」 |
| 课堂模式 | 「面批制 + 当堂清」，小班化 |
| 体育合作 | 与南京玄武体校深度合作 |
| 特色项目 | 艺术体操、花样游泳（省市级多项奖牌） |

### 2.3 校园设施 `[A]`

| 类别 | 设施 |
|---|---|
| 教学 | 各学年教室、功能教室、演讲厅、DT 功能教室、图书馆（藏书超 2 万册） |
| 艺术 | 大型多功能剧院、迷你剧院、黑匣子剧场、艺术中心、音乐教室 |
| 运动 | 室内游泳馆、羽毛球馆、排球馆、体育馆、**攀岩墙**、户外体育场、足球场、网球场 |

> **判断**：书人的硬件配置在其学费档位（23,500 元）中属**较优水平**，尤其「三剧场 + 恒温泳池 + 攀岩墙」的组合，硬件亮点突出。

## 九、家长口碑与评价（`[C]`，需自行甄别）

**优势共识**

- **升学数据江北领先**：均分浦口区第一、六大率约 70%、四星率 100%
- **上升势头明确**：2024 → 2025 年均分涨 15 分以上，附中达线从 25 → 39 人
- **特长生/拔尖渠道**：2024 届 16 人特长生录取，含南外丘班、一中丘班
- **硬件配置突出**：三剧场 + 恒温泳池 + 攀岩墙 + 藏书 2 万册图书馆
- **体育特色**：与玄武体校合作，艺术体操、花样游泳获奖
- **提供住宿**：适合跨区家庭
- **国际课程通道**：高中部设 IGCSE/A-Level 方向

**争议与关注点**

- ⚠️ **学费全市中高档（23,500）**，且为**江北新区民办最高档**
- ⚠️ **公开信息透明度偏低**：师资数据、完整中考明细未公开
- ⚠️ **规模小（约 6 个班/届）→ 指标生基数小**
- ⚠️ **样本量小**：参考人数仅约 148 人，数据的统计波动性较大
- ⚠️ **2025 六大率口径不一**（70% vs 71.6%），需谨慎引用
- ⚠️ **集团背景为培训机构出身**，家长对其「全日制办学沉淀」的成熟度存在观望
- 高中部投档线（551 分档）不高，体系内升学价值有限
- 校区位于江北新区浦乌中路，**对江南家庭通勤距离较远**

## 十、择校小结

### 适合的学生画像

| 维度 | 判断 |
|---|---|
| 冲六大名校 | ★★★★☆（六大率约 70%） |
| 求四星托底 | ★★★★★（四星率 100%） |
| 冲竞赛/丘班/科技特长 | ★★★★☆（丘班输送渠道） |
| 江北新区自住 | ★★★★★ |
| 需要住宿 | ★★★★☆（提供住宿） |
| 在意学费性价比 | ★★★☆☆（江北最高档学费） |
| 重视信息透明度 | ★★☆☆☆（公开信息少） |
| 江南家庭通勤 | ★★☆☆☆（跨江） |

### 关键决策变量

1. **升学数据是硬实力**：书人 2025 届六大率约 70%、四星率 100%、均分浦口区第一，**在江北民办中处于领先**，且处于上升通道。这是其核心竞争力。
2. **学费是江北民办最高档**：23,500 元/学期，比同区育英二外（19,000）、晓庄实验（16,600）明显更高。**溢价需以「升学 + 硬件 + 住宿」综合衡量**。
3. **规模小意味着「样本波动」**：一届仅约 148 人参考，升学比例的年度波动可能较大。建议**索取近三年完整数据**再作判断。
4. **江北 vs 江南的选择题**：书人位于江北新区浦乌中路，江南家庭需考虑跨江通勤或住宿。若家庭本身在江北，书人是**区内第一梯队**的优选。
5. **与明道、育英二外的对比**：明道（学费 20,900，六大率 45%）、育英二外（19,000，四星率超 80%）在江北同样热门。**若以六大率为首要目标，书人数据领先；若以学费敏感，育英二外更实惠。**
