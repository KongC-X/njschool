## 二、基本情况

### 2.1 创办背景

考棚小学**始建于 1905 年**，前身是「**程子祠学堂**」，建校于「**下江考棚**」程子祠遗址。**1927 年改名「考棚小学」**。学校现位于风景秀丽的秦淮河畔。`[A]`

学校坚持以周恩来「**为中华之崛起而读书**」的至理名言为校训，激励全体师生，形成了优良的校风、教风与学风，在市、区享有较高声誉。`[A]`

> **解读**：考棚小学的校名来自「考棚」——即古代科举考试的考场（下江考棚），其所在地是明清科举文化的空间遗存。**校名本身即承载着「读书应试、报效国家」的历史意涵**，与「为中华之崛起而读书」的校训天然契合。`[A]`

### 2.2 发展沿革

| 时间 | 事件 |
|---|---|
| 1905 年 | 建校于下江考棚程子祠遗址 |
| 1910 年 | 改名「程子祠学堂」 |
| 1912 年 | 学校改为高级小学校 |
| 1927 年 | 改名「考棚小学」，恢复为完全小学 |
| 1931 年 | 实行教训分开，设教导处、训育处、总务处 |
| 1940 年 5 月 | 更名为「南京特别市第十六完全小学」 |
| 1946 年 | 更名为「南京市第四区中心国民学校」 |
| 1949 年 | 恢复校名「南京市考棚小学」 |
| 2013 年 | 与原营养学校长乐路校区合并 |
| 2015 年 | 完成校舍改造，建成**正心楼、启智楼**等教学设施 |
| 2025 年 | 成为**江苏第二师范学院基础教育集团附属学校** |

> **解读**：考棚小学经历了从「考棚书院文化」到「现代完小」的完整转型，1949 年恢复「考棚小学」校名后延续至今。**2025 年成为江苏第二师范学院基础教育集团附属学校**，是其近年最具分量的发展节点——获得了高校（江苏第二师范学院）的专业资源支持。`[A]`

### 2.3 办学规模

- **占地面积**：5,382 平方米；**建筑面积**：5,566 平方米 `[C]`

- 学校位于风景秀丽的**秦淮河畔**，地址为许家巷 15 号 `[A]`

## 三、办学特色

### 3.1 办学理念

考棚小学以**周恩来精神**为校魂，办学理念为「**以恩来精神建校育人**」。`[A]`

学校明确的**办学目标**：力争使学校成为「教育质量高、办学特色明、文化内涵深、在全省具有一定影响的现代化学校」。`[A]`

学校明确的**三大办学特色** `[A]`：

| 类别 | 特色 | 内涵 |
|---|---|---|
| **德育特色** | 充满关爱 | 意在弘扬仁爱精神，彰显人文关怀 |
| **教学特色** | 大胆追问 | 旨在倡导自主探究，培养科学精神 |
| **课程特色** | 双语教育 | 重在营造语言环境，积蓄发展潜力 |

### 3.2 特色课程与校园文化

| 项目 | 说明 |
|---|---|
| **「周恩来班」** | 学校创建了**全国小学中第一个「周恩来班」** |
| **「翔宇」系列校园文化** | 精心建设「翔宇」系列校园文化（「翔宇」为周恩来的字） |
| **「明理课堂」** | 近年构建「明理课堂」教学范式 |
| **「三个一」作业管理模式** | 实施「三个一」作业管理模式 |
| **「四色社团」体系** | 设立「四色社团」体系 |
| **物联网种植基地** | 劳动与科技教育融合 |
| **智慧校园电子班牌睡眠管理系统** | 探索学生睡眠管理的信息化手段 |
| **「快乐体育」** | 开展深受学生喜爱的「快乐体育」活动 |
| **学习型青年教师群体** | 优先启动创建学习型青年教师群体工作，确立省级教育科研规划课题 |

### 3.3 特色项目与荣誉

学校先后荣获南京市实验小学、南京市示范学校、南京市德育先进学校、南京市教育科学研究先进单位、南京市科技教育特色学校、江苏省现代教育技术实验学校、全国群众体育先进单位等多项殊荣。`[A]`

少先队大队被表彰为**全国红旗大队**。`[A]`

> **解读**：考棚小学的特色**高度围绕「周恩来精神」这一人格榜样**展开——「周恩来班」「翔宇文化」「为中华之崛起而读书」校训，形成了一条「榜样引领→德育实践→校园文化」的完整链条。这与夫小的「孔子文化」路径异曲同工，都是「以文化人」的德育型名小。`[A]`

| 追求大规模激烈竞争氛围 | ★★☆☆☆（规模中等偏小，生源在收缩） |

**关键决策变量**

1. **对口文枢初中的定位**——考小对口文枢初中（西片）。文枢初中的公开成绩数据有限，**建议实地了解其发挥与升学表现**，作为判断考小通路价值的关键。
2. **生源规模变化的趋势**——家长圈口径称新一年级仅 2 个班 77 人，若属实，反映老城片区生源收缩。**2026 年派位计划 50 人、报名 119 人、摇中率约 42.0%**，竞争强度明显低于同级别热点校，可与上述判断相互印证。**这一趋势对学校氛围与竞争强度均有影响，需核实招生计划。**
3. **「恩来精神」特色是否匹配**——考小是典型的德育型名小，适合重视品格养成与精神榜样教育的家庭。
4. **高校附属后的资源变化**——2025 年成为江苏第二师范学院基础教育集团附属学校，可关注其后续的教研与师资提升。
