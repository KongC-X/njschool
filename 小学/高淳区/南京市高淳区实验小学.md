## 二、基本情况

### 2.1 创办背景与校史沿革

高淳区实验小学**创建于 1905 年**，学校前身是**清道光八年（1828 年）建立**的「**学山书院**」，光绪三十一年（1905 年）改为「**高淳县学堂**」。`[A]`

| 时间 | 事件 |
|---|---|
| **清道光八年（1828 年）** | 建立「学山书院」（学校前身） |
| **清光绪三十一年（1905 年）** | 「学山书院」改为「高淳县学堂」（学校创建年份） |
| **1949 年 5 月** | 高淳解放后，定校名为「高淳县城区小学」 |
| **1952 年** | 首次附设幼儿班 |
| **1969 年** | 改名为「高淳电厂东方红学校」 |
| **1978 年** | 经镇江地区批准为**县重点小学** |
| **1979 年** | 恢复原校名 |
| **1981 年 3 月** | 经江苏省教育厅批准为**全省首批办好的实验小学之一** |
| **1998 年 5 月** | 更名为「高淳县实验小学」 |
| **2012 年 12 月** | 被评为**南京市青奥示范学校（现代化示范学校）** |
| **2025 年** | 迎来**建校 120 周年** |

`[A]`

> **解读**：高淳实小是一所**近两百年文脉的学校**——办学源头可追溯至 1828 年的学山书院，正式创建于 1905 年。学校 1981 年即跻身「全省首批办好的实验小学」，与溧水实小（同年）、六合实小（1914 年建校、1996 年入选江苏名小学）同属南京区县老牌名校序列。**「学山」不只是地名，而是学校文化体系的核心意象**。`[A]`

### 2.2 学校定位

高淳实小是高淳区公办小学的**龙头校**，在家长圈中长期被视为区内第一梯队。`[C]` 学校 2025 年迎来 120 周年校庆，官方媒体给予专题报道，社会关注度高。`[A]`

## 三、办学特色

### 3.1 办学理念与「学山」文化

学校**核心理念为「亲仁近智」**——强调亲近仁德、接近智慧。学校以「**学山**」为核心点，逐步形成了具有校本特色的「**学山**文化」：以儿童为中心，确立了**根植本土历史、崇尚好学力行、注重民族文化的传承**，注重学生学习素养、学习精神、学习境界的培育模式。`[A]`

**高淳实小校训校风体系** `[A]`：

| 类别 | 表述 |
|---|---|
| 核心理念 | 亲仁近智 |
| 校训 | 好学　力行 |
| 校风 | 文明　团结　求实　创新 |
| 教风 | 严谨治校　精通业务　热爱学生　乐于奉献 |
| 学风 | 勤奋好学　精思好问　生动活泼　全面发展 |

> **解读**：与溧水实小的「高平」文化类似，高淳实小的「**学山**」文化同样**直接源自其书院前身**（学山书院）。校训「好学力行」呼应书院「学山」意象，校园建筑「学山阁」「明伦阁」亦延续这一脉络。这种「书院—学校」一脉相承的文化叙事，是老校区别于新建校的核心资产。`[A]`

### 3.2 课程与社团

学校开设门类丰富的校本课程与社团 `[A]`：

| 类别 | 内容 |
|---|---|
| 书画 | **学山少儿书画院**（墨香流淌） |
| 科技 | **少儿科学院** |
| 教学创新 | **力行课堂**、「**AI + 非遗**」教学创新融合 |
| 体育 | **武术**（特色大课间）、龙狮、球类 |
| 艺术 | 篆刻、美术、合唱、课本剧 |
| 课后服务 | 每周三、周六组织多彩社团活动；课后服务时段学生自主学习、静心阅读，教师耐心答疑、一对一辅导 |

### 3.3 体育特色

学校体育特色鲜明 `[A]`：

- 设有**国家级体育俱乐部**
- **武术特色大课间**全面落实「2·15 专项行动」，制定「微行养品」快乐课间实施方案，践行课间活动「1+N」项目
- 在**阳光体育大课间评比中获区一等奖**

> **看点**：高淳实小既有「**学山少儿书画院**」的书香底色，又有「**武术 + 龙狮**」的刚健一面，「亲仁近智」与「好学力行」在课程上形成了柔刚相济的搭配。`[A]`

### 3.4 融合教育与人文关怀

学校在融合教育方面有具体实践 `[A]`：为患有脊髓性肌萎缩症的二年级学生提供支持，允许其 70 岁外公作为「**编外人员**」入班陪读，协助完成课堂活动，并专门提供休息室用于课后放松。此举体现了「亲仁」理念在真实教育场景中的落地。

### 3.5 品格提升工程

学校承担**省级品格提升工程**，并设有「学山荷韵·共育成长」等社区共育活动（与河滨社区党总支共办新春主题活动），开展环保小卫士、垃圾处理站参观等春季社会实践，与高校合作开展实习巡视和**双导师制**。`[A]`

### 5.2 招生方式

- **公办施教区免试就近入学**：适龄儿童少年应具有所在施教区户口，原则上与父母（法定监护人）同一户籍，且户籍与房产证（不动产权证）「**一致**」`[A]`
- **多校划片**：部分区域设多校划片，符合条件的家庭可申请（如宝塔/新城/淳溪中心三校可申请南师附中高淳学校小学部）`[A]`
- **电脑派位**：本区户籍适龄儿童少年，可在**民办学校、热点公办学校和南京外国语学校中最多选 2 所**报名 `[A]`
- **长幼随学**：自 2026 年秋季学期起试行 `[A]`
- 录取后不得被其他学校再次录取，也不得回施教区学校就读 `[A]`

### 5.4 入学条件要点 `[A]`

- **年龄**：年满六周岁（2019 年 9 月 1 日—2020 年 8 月 31 日期间出生）
- **户口**：适龄儿童少年应具有所在施教区户口，原则上与父母（法定监护人）同一户籍
- **房产**：户籍与房产证（不动产权证）一致；**房产用途须为住宅用房**（商业、工业、办公、阁楼、地下室、车库等不能作为入学依据）；共有产权须法定监护人拥有 **51% 及以上**产权
- **拆迁户**：按安置房是否分配、是否交付分三种情形处理
- **随迁子女**：非南京市户籍适龄儿童少年，符合条件者由区招考中心统筹安排入学
- **户籍空挂**：户籍登记在非法定监护人房产上的，由区教育局统筹安排

## 六、升学表现

### 6.1 对口初中

小学阶段南京**没有官方「升学率」指标**，公办小学的出口质量由**对口初中的中考表现**间接体现。

**高淳区实验小学的对口初中为「南京市高淳区第二中学」** `[B]`。

> **判定依据**：
> ① 第三方教育信息平台明确表述「高淳二中**生源主要来自于区实验小学和古柏中心小学**」`[B]`；
> ② 高淳二中（2021 年一度称「南京一中高淳分校」）施教区为「沿宝塔路—固城湖北路—镇兴路—太安路—芜太路—官溪路—湖滨大道—宝塔路所形成的区域」，与**高淳实小施教区（石臼湖南路—石臼湖北路—镇兴路—太安路—芜太路—官溪路—湖滨大道）在「镇兴路—太安路—芜太路—官溪路—湖滨大道」段高度重合**，几何对应清晰 `[A]`。
>
> **口径提示**：入学网称高淳实小对口「南京市高淳区第三中学」`[C]`——**第三中学**的施教区边界为「…芜太路—**水阳江路**—宝塔路」，与实小施教区的「官溪路—湖滨大道」段不对应（「水阳江路」段与**宝塔小学**施教区更吻合）。**本档案以「第二中学」为主流口径，并将此差异列入数据缺口。** `[A]/[C]`

## 九、择校视角小结

**适合的家庭画像**

| 维度 | 判断 |
|---|---|
| 高淳区淳溪街道自住 | ★★★★★（区内龙头，对口明确） |
| 看重历史底蕴与文化传承 | ★★★★★（1828 年学山书院源流，120 周年校庆） |
| 重视书画、科技、体育特长 | ★★★★☆（学山少儿书画院、少儿科学院、武术龙狮） |
| 看重师资结构与透明度 | ★★★★☆（公开完整师资数据，骨干占比约 43%） |
| 依托高淳区指标生通道 | ★★★★☆（省淳中指标生控制线 574 分） |
| 追求主城顶尖名校 / 南外 | ★★☆☆☆（区位与出口天花板受限） |
| 要求通勤便利 | ★★☆☆☆（高淳区距主城较远） |

**关键决策变量**

1. **区内龙头的确定性**——高淳实小近两百年文脉、1981 年省首批实验小学，是高淳区最稳妥的选择，「下限保障」扎实。
2. **对口初中需单独核实**——主流口径为**高淳区第二中学**，入学网称第三中学。第二中学 1979 年建校、省级示范初中、生源主要来自实小与古柏中心小学，与实小施教区几何对应清晰。**建议以当年高淳区小升初施教区文件为准**。
3. **省淳中的招生范围优势**——江苏省高淳高级中学**面向「高淳区 + 原市区」招生**，2022—2025 连续四年囊括南京市七项大奖，是高淳区学生的重要出口；区内指标生控制线 **574 分**（比统招线低 11 分）。
4. **「学山」文化的独特价值**——从学山少儿书画院到 AI+非遗、武术龙狮，学校在传统文化与现代科技之间形成了自己的表达，适合看重文化底蕴与素质教育的家庭。
5. **施教区需对照地图核实**——官方为「道路合围」表述，建议对照高淳区地图确认房产是否落入范围内。
