## 二、基本情况

### 2.1 七十年校史：一所「被拆迁推着长大」的学校

摄山星城小学的校史，是南京近郊城镇化最完整的样本之一。学校官方梳理的沿革脉络如下 `[A]`：

| 时间 | 事件 |
|---|---|
| **1952 年** | 创办，因校舍建在**竹丝巷村**，得名「**竹丝巷小学**」；规模仅**一个一至四年级复式班** |
| **1976 年** | 异地重建，更名「**摄山乡朝阳小学**」，办学规模为**单轨一所完小** |
| **1988 年** | 校舍再次向东易址，办学规模不断扩大 |
| **1993 年** | 升级为「**摄山中心小学**」 |
| **1995—2005 年** | 因地方办学布局调整与**仙林大学城拆迁用地**，周边**赵庄、向阳、摄山、东湖、漳桥、向前、红梅、东花、江嵊、东阳、梨花闸、西岗**共 **12 所小学**陆续拆并至此 |
| **2000 年** | 栖霞、摄山两乡镇合并；学校第三次异地新建至现址，校名仍为「摄山中心小学」，办学性质一度变为**村小** |
| **2005 年** | 更名「**摄山星城小学**」 |
| **2009 年** | 西岗街道办事处成立，学校**再次升级为中心小学** |
| **2014 年 9 月** | **天佐路校区**建成启用，形成「一校两校区」格局 |

> **解读**：这条时间线里藏着三件事。
>
> **第一，它是一所「合并出来的学校」。** 12 所村小并入，意味着今天的学生家庭来自十几个不同的村落——赵庄、向阳、东湖、漳桥、向前、红梅、东花、江嵊、东阳、梨花闸、西岗、摄山。每一所被撤并的村小，都曾是某个村子的文化中心。摄小承接的不只是学生，还有这 12 个村子的集体记忆。学校后来把这件事做成了校园景观——「**竹丝幽巷**」「**江乘故邑**」「**东阳古邨**」「**红梅枫岭**」「**梨花问闸**」「**上泉乡社**」「**西岗曲径**」七个景点，正对应这些消失的村名。`[A]`
>
> **第二，它经历过「降格」。** 2000 年第三次迁建后，学校性质一度从「中心小学」变成「村小」，直到 2009 年西岗街道成立才重新升格。这种行政级别的反复，在南京学校中极为少见，也解释了为什么学校今天对「中心校」身份与「星光」品牌建设如此着力。
>
> **第三，它的成长与仙林大学城同步。** 1995—2005 年正是仙林大学城大规模征地拆迁的十年。学校每一次扩张，背后都是一次拆迁安置的人口导入。可以说，**摄山星城小学的校史就是西岗片区的城市化史**。

### 2.2 施教区（2026 年官方公布）`[A]`

据《南京市栖霞区2026年公办小学一年级招生施教区范围》原文照录：

> **施教区范围**：朝阳路校区：摄山星城步青路以东片区、孟北村、桦墅村、西岗村（代招西岗家园）；天佐路校区：摄山星城步青路以西片区（含枫霞雅苑）、西花社区、东阳社区（不含河北队）、红梅村社区（下梅墓）

按校区拆分对照：

| 校区 | 施教区范围（原文） |
|---|---|
| **朝阳路校区** | 摄山星城步青路以东片区、孟北村、桦墅村、西岗村（代招西岗家园） |
| **天佐路校区** | 摄山星城步青路以西片区（含枫霞雅苑）、西花社区、东阳社区（不含河北队）、红梅村社区（下梅墓） |

**三个必须看清的限定语：**

| 限定语 | 所在校区 | 含义 |
|---|---|---|
| **步青路为界** | 两校区之间 | 摄山星城小区被步青路一切为二：以东归朝阳路校区，以西归天佐路校区。**同一个小区可能分属两个校区** |
| **代招西岗家园** | 朝阳路校区 | 西岗家园属「代招」，即非本校正式施教区，而是受区教育局委托接收。代招关系可能随学位情况调整 |
| **不含河北队 / 仅下梅墓** | 天佐路校区 | 东阳社区只取「不含河北队」的部分（河北队划归龙潭中心小学江畔人家校区）；红梅村社区只取「下梅墓」这一片 |

> **解读**：这四条限定语，是本档案六所学校中施教区表述最复杂的一份。家长最容易出错的两处是：
> 1. **只记住「摄山星城」四个字**——但小区被步青路切成两半，两半属于不同校区，两个校区的校址、师资、对口班级都不同。
> 2. **把「东阳社区」「红梅村社区」整块算进来**——实际只取其中一部分（东阳不含河北队、红梅仅下梅墓）。这两个「部分」与摄山初级中学的施教区表述完全一致，属**小学—初中同片对口**的设计。
>
> 判定的唯一可靠办法：**拿门牌号去比对当年区教育局文件**，不要用「我家在摄山星城」这种模糊说法。

### 2.3 与初中施教区的对应关系

| 小学（校区） | 对应初中施教区表述 | 一致性 |
|---|---|---|
| 摄山星城小学 朝阳路校区 | 摄山初级中学：西岗街道所辖区域（不含金中仙林施教区） | 部分对应 |
| 摄山星城小学 天佐路校区 | 摄山初级中学：红梅村社区（下梅墓）、西花社区、东阳社区、矿机宿舍区 | **高度一致** |

> **解读**：天佐路校区的施教区（西花、东阳、红梅下梅墓）与摄山初级中学的三个单列社区**逐条对应**，说明这一片是「小学—初中」直通设计。朝阳路校区覆盖的孟北、桦墅、西岗、步青路以东片区，则落在摄中「西岗街道」这个大筐里，但需注意扣除金中仙林中学部的地界。

### 2.4 校园：「五园二十四景」`[A]`

学校把 22,000 ㎡的校舍与 72 亩校园，做成了系统的物型课程：

| 园区 | 主要景点 | 教育指向 |
|---|---|---|
| **门外与门厅** | 「群星荟萃」文化墙、阅读大厅「七彩星吧」 | 归属感、阅读 |
| **第一园：星移斗转** | 「摄山」石、「孺子牛」石、卓子亭 + 七景（竹丝幽巷、江乘故邑、东阳古邨、红梅枫岭、梨花问闸、上泉乡社、西岗曲径） | **乡土记忆**、地名文化 |
| **第二园：星灵记忆** | 乐学长廊、**数趣广场**、萌星舞台 | 数学体验、儿童剧展演 |
| **第三园：星汉灿烂** | 燕子来桥、漳桥临界、龙泉胜境 | 水景、地域交汇 |
| **第四园：承星履草** | **星娃农场**、百草合欢、当思来处 | 劳动、节俭 |
| **第五园：星城鼓舞** | 村歌社鼓、鼓场点兵、鼓角相闻 | 体育、鼓舞文化 |
| 室内 | **星光剧场**（大型室内体育场） | 演出、集会 |

**细节值得单说：**

- 「**卓子亭**」之名取自江嵊小学最早的校舍借驻的「卓子庙」，寓意「星城小学的孩子人人都是卓越学子，人人都是明星」；亭上楹联由本校教师自拟：「信步廊亭话摄山故事，问学诗书谱栖霞新歌」「林下听花香鸟语，窗外应琴韵书声」。`[A]`
- 「**摄山**石」得名于老摄山镇，前刻「摄山」二字，取传承之意；「**孺子牛**石」以形命名，喻教师「俯首甘为孺子牛」。`[A]`
- 「**竹丝幽巷**」直接指向 1952 年的建校起点——「山上有竹，竹下有村，村有幽巷」。`[A]`
- 获评**南京市园林式校园**创建（学校自述「创建园林式校园，美化育人环境」）。`[A]`

> **解读**：这套「五园二十四景」的设计水平，在南京公办小学中属于**上乘**。它的高明之处在于：**每一个景点都对应一个真实消失的村名或一段真实的校史**，不是凭空造景。孩子每天走过「梨花问闸」，就是在与一个已经拆迁消失的村庄发生联系。对一所合并了 12 所村小的学校，这是最恰当的「记忆保存」方式——**把乡愁做成课程**。

## 三、办学特色

### 3.1 办学理念：「星光」文化 `[A]`

| 要素 | 内容 |
|---|---|
| 文化标识 | **星光** |
| 核心精神 | **闪亮每一个** |
| 办学理念 | **同心同光，美若天成** |
| 校训 | **启明**（早期表述为「修文星之才，立美善之品」） |
| 隐喻 | 每一位师生都是「浩瀚星空中的点点繁星」，都有闪光点 |
| 教育行动 | 通过学校教育行动**点燃自信**，为终身发展奠基 |
| 办学愿景 | 「文韵飘香的智慧学园，星光璀璨的品牌校园」 |
| 学生称谓 | **星童** / 星城学子 |

> **解读**：「闪亮每一个」是一句有风险的理念——它承诺的是**普惠性的被看见**，而不是「培养尖子」。在 42 个班、1,615 名学生的规模下，兑现这句话的难度极高。学校给出的答案是**把舞台做多**：儿童剧（班班有剧、人人能演）、数趣广场、星娃农场、鼓舞、柔道、太极、无线电测向——**项目越多，孩子被看见的概率越大**。这套逻辑是成立的，但资源摊薄的风险也真实存在。

### 3.2 特色一：儿童剧（小星星萌剧园）`[A]`

这是摄山星城小学**辨识度最高的品牌**。

| 项目 | 内容 |
|---|---|
| 品牌名 | **小星星萌剧园** |
| 定位 | 「班班有剧、人人能演」 |
| 代表剧目 | 《蛋蛋圆梦记》《小明青奥梦》《青鸟》《马兰花》《我要飞》 |
| 创作方式 | **师生共同创作**并成功演出 |
| 成果 | 多部课本剧在市、区获奖 |
| 载体 | 「萌星舞台」（第二园星灵记忆内），以学校主题文化墙为背景 |
| 剧场 | 星光剧场（室内大型体育场） |

> **解读**：儿童剧是这所学校最「费功夫」的特色。它的成本极高——排一部剧要占用大量课余时间、需要服装道具舞美、要协调几十个孩子的档期。但它对学生的锻炼也最全面：语言表达、肢体控制、团队协作、抗压、公共表达。对一所生源以拆迁安置家庭为主的小学，**戏剧可能是最平等的素质教育**——它不挑天赋，只挑投入。
>
> 《小明青奥梦》这个剧名值得注意：青奥会 2014 年在南京举办，学校当时以此为题创作，说明其儿童剧创作有**紧跟城市大事**的传统，不只是排童话。

### 3.3 特色二：「数趣广场」数学体验课程 `[A]`

| 项目 | 内容 |
|---|---|
| 课程群名 | **数趣广场** |
| 空间载体 | 第二园「星灵记忆」内的地面刻印区 |
| 内容 | 跳格子、攻城池、七巧板、九宫格等**童年数学游戏** |
| 课程目标 | 「**用数学看世界**」 |
| 建设路径 | 打造数学学习体验空间 → 开发体验学习课程 → 开展体验学习活动 |
| 成果 | 获市区重要教育教学成果 |

> **解读**：把数学游戏刻在地上，让孩子课间用脚去「玩数学」，这是很低成本、很高频的做法。它解决的是小学数学最普遍的痛点：**抽象符号与身体经验脱节**。数趣广场把「七巧板」「九宫格」从纸面搬到地面，孩子在跳格子时自然习得数感与空间感。
>
> 这套课程群能拿到市级教学成果，说明学校做了**课程化包装**（不只是添置设施），有目标、有序列、有评价。这是判断一所小学特色「真做还是假做」的关键区别。

### 3.4 特色三：体育与科技社团 `[A]`

| 项目 | 说明 |
|---|---|
| **柔道** | 特色体育项目，在小学中较为少见 |
| **太极** | 传统文化体育项目 |
| **无线电测向** | 科技体育项目，需专业指导与设备 |
| **「鼓动星城」/ 鼓舞** | 与第五园「星城鼓舞」呼应，含鼓乐与集体舞 |
| 科技教育 | 南京市科技教育特色学校；江苏省青少年科技活动三星级先进集体 |

> **解读**：**柔道 + 太极 + 无线电测向**这个组合很有意思——它同时覆盖了对抗性运动、传统养生、科技体育三个方向，且都不是「足球篮球」这类大路货。这说明学校在特色项目选择上有过认真考量：**避开与大学城周边学校同质化竞争，选择门槛较高、易出成绩的小众项目**。无线电测向尤其如此——它需要器材、场地与专业教练，一旦建成就有壁垒。

## 四、师资力量

### 4.1 师资结构 `[A]`

| 专任教师 | **139 人** |

| 在校学生 | 1,615 人 |

**推算指标：**

| 指标 | 数值 | 说明 |
|---|---|---|
| 师生比 | 约 **1:11.6**（按专任教师 139 人计） | 优于南京市小学平均水平 |
| 班师比 | 约 **1:3.3**（按专任教师计） | 每班约 3.3 名专任教师 |
| 平均班额 | 约 **38.5 人** | 低于 45 人标准上限 |
| 骨干教师占比 | 约 **36.7%** | 在区属小学中属较高水平 |

> **解读**：这组数字是摄山星城小学最硬的底气。
>
> **名优骨干占比 36.7%**——这个比例在南京区属小学里不低。区级及以上骨干（含区学科带头人、区优青、市优青、市学带）通常需要 8—10 年积累，一所城郊小学能达到三分之一以上，说明其教师队伍**不是「新校新教师」结构，而是有沉淀的成熟队伍**。
>
> **师生比 1:11.6、班额 38.5 人**——两项都优于南京公办小学的常见水平（部分热点校班额可达 45—50 人）。对家长最直接的意义是：**孩子被个体关注的可能性更高**。

### 4.2 师资建设的可能隐忧

| 隐忧 | 分析 |
|---|---|
| **两校区师资均衡** | 天佐路校区 2014 年才建成，新校区通常配置年轻教师。两校区师资成熟度可能存在差异，公开信息未分校区披露 |
| **骨干教师年龄结构** | 51 名骨干若集中在某一年龄段，未来 5—10 年可能集中退休，形成断档 |

### 5.5 2026 年政策变化提示

2026 年南京公办小学入学政策有实质松绑：**不再要求提前一年落户、取消学区房持有年限限制、取消「一套住房六年内一名学生」的学位锁定**（小学口径）。`[C]`

### 6.3 如何评估这所小学的「出口」

小学阶段不存在官方「升学率」。评估一所小学的出口质量，实际应看三件事：

| 维度 | 摄山星城小学的情况 |
|---|---|
| **对口初中的中考表现** | 摄中 2024 年中考「一分三率」全面达标、连续四年区综合评估一等奖（定性，无具体百分比）`[A]` |
| **指标生通道** | 摄中非热点校、规模中等，校内前列学生争指标的难度低于城区大校 |
| **个体上限** | 无公开的南外/民办录取数据 |

> **解读**：摄山星城小学 + 摄山初级中学，构成一条**「稳定但不惊艳」的九年通路**。它的优势是路径确定、竞争温和、指标生性价比高；短板是缺少拔尖出口的可验证证据。家长如果对孩子有更高的升学期待，需要考虑在小学阶段额外投入（民办报考、南外备考、学科拓展），而不能完全依赖校内。

## 九、择校视角小结

### 适合的家庭画像

| 维度 | 判断 |
|---|---|
| 家住西岗街道/摄山星城/孟北/桦墅/西岗村 | ★★★★★（就近入学，无替代选项） |
| 重视素质教育与活动体验 | ★★★★★（儿童剧、数趣广场、农场、鼓舞、柔道） |
| 希望孩子被「看见」而非只被排名 | ★★★★☆（「闪亮每一个」理念 + 多舞台设计） |
| 看重师资成熟度与骨干比例 | ★★★★☆（骨干占比约 36.7%） |
| 希望小升初路径确定 | ★★★★★（直升摄山初级中学，单校对口） |
| 预算有限、不接受学区房溢价 | ★★★★★（板块无学区溢价，安置房/刚需房为主） |
| 追求南外/民办等拔尖出口 | ★★☆☆☆（无公开数据支撑，需额外投入） |
| 要求透明量化教学质量 | ★★☆☆☆（官方数据稀缺） |

### 关键决策变量

1. **先确定是哪个校区**——摄山星城小区被**步青路**分为东西两半，分属朝阳路校区与天佐路校区。两校区校址不同、建校时间差 60 年。**不要只问「是不是摄小」，要问「是哪个校区」**。
2. **核实「代招」的稳定性**——朝阳路校区「代招西岗家园」。代招关系不是正式施教区，可能随学位情况调整。西岗家园的家庭应每年重新确认。
3. **东阳、红梅的「部分」要看清**——东阳社区**不含河北队**（归龙潭中心小学江畔人家校区），红梅村社区**仅下梅墓**。这两处最容易误判。
4. **两校区的实际差异要实地看**——天佐路校区 2014 年建成，硬件新；朝阳路校区历史长、文化积淀厚。师资配置是否均衡、班级规模是否有差异，公开信息未披露，建议开放日分别走访。
5. **特色项目的「可参与性」**——儿童剧、柔道、无线电测向都是**选拔性或限额**项目，不是人人可参加。入学前应问清：一年级有哪些普惠性社团？选拔在什么时候？
6. **对口初中的实际水平**——摄中 2024 年中考「一分三率」全面达标，但无具体百分比。若在意升学，建议向在校初中家长了解近三年四星高中录取的绝对人数。
