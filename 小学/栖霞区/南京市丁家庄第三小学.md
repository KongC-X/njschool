## 二、基本情况

### 2.1 创办背景：片区组团的最后一块拼图

丁家庄第三小学 2019 年 9 月开办，是丁家庄保障房片区四校组团的**最后落位者**。时间线清晰 `[A]`：

| 年份 | 学校 | 备注 |
|---|---|---|
| 2014.9 | 南京市丁家庄小学 | 片区第一所小学 |
| 2014.9 | 南师附中丁家庄初级中学 | 与丁小同年，初中先行 |
| 2017.9 | 南京市丁家庄第二小学 | 片区第二所小学 |
| 2019.9 | **南京市丁家庄第三小学** | 片区第三所小学，组团收官 |

2019 年开办时，本地媒体的表述是「迈小集团又将迎来一名新成员」，并强调学校「**毗邻南京地铁 7 号线丁家庄站点，交通十分方便**」，「它的建立，将为迈小集团注入新的活力」。`[B]`

> 值得注意的是，**初中（2014）先于第二、第三所小学（2017、2019）建成**。这个顺序说明丁家庄片区的教育规划是按「初中先行、小学随人口入住逐步补齐」的逻辑推进的——先立住出口，再随居住组团交付节奏开设小学。这也解释了为什么三所小学全部对口同一所初中：**它们本来就是为同一所初中配套的三个生源入口。** `[C]`

### 2.2 片区定位：三校边界与「万寿村」的特殊性

按 2026 年栖霞区教育局公示，丁家庄三小的施教区为 `[A]`：

> **万寿村社区（不含依云华府、燕华花园）、瑞丰园社区、秋韵园社区**

这是三校中**唯一带明确排除项**的施教区，也是唯一包含「村」级社区的。

**逐项拆解**：

| 单元 | 类型 | 说明 |
|---|---|---|
| 万寿村社区（不含依云华府、燕华花园） | 原行政村转社区 | 万寿村原是迈皋桥镇下辖行政村，城市化后转制为社区 |
| 瑞丰园社区 | 保障房居住组团 | 丁家庄片区居住组团 |
| 秋韵园社区 | 保障房居住组团 | 丁家庄片区居住组团 |
| **依云华府**（排除） | 商品房小区 | 明确不在三小施教区 |
| **燕华花园**（排除） | 商品房小区 | 明确不在三小施教区 |

**这个排除项是本片区最需要留意的技术细节。** 排除意味着依云华府、燕华花园虽地理上可能邻近三小，但被划给了其他学校。家长若只按「离得近」判断，极易误判。`[A]`

**与兄弟校的边界对照**：

| 学校 | 施教区 | 特征 |
|---|---|---|
| 丁家庄小学 | 春晓园、景和园、山水园、馨合园 + 紫金北郡、银贡山庄、熙景福苑 + 兴卫村（兴都片区） | 最广，含 3 个商品房 + 村社片区 |
| 丁家庄第二小学 | 汇虹园社区 | 最窄，单一社区 |
| **丁家庄第三小学** | **万寿村（不含依云华府、燕华花园）、瑞丰园、秋韵园** | **唯一带排除项，含村社** |

> **关键提醒**：三校施教区**互不重叠、无一社区共用**。这意味着丁家庄片区不存在「一个社区对应两所学校、家长可二选一」的情况，也没有「多校划片」——**社区归属直接唯一决定学校**，没有选择空间。`[A]`

### 2.3 办学规模：一个仍在生长的学校

三小的规模数据是四校中最不透明的。可确认的信息只有 `[B]`：

- 2019 年 9 月首招一年级
- 2020—2021 学年时仅有一、二年级（「虽然只有两个年级」）
- 至 2025 年应已完整覆盖六个年级（2019 年入学的一年级于 2025 年毕业）

> **重要含义**：三小在 2025 年之前**没有完整的六年培养周期样本**，2025 年才产生首届毕业生。这意味着：
> 1. 学校的小升初出口表现，2025 年才开始有第一批可观测数据
> 2. 学校在 2019—2024 年间长期处于「每年新增一个年级」的扩张状态，教师招聘、课程建设、文化沉淀都是滚动进行的
> 3. 家长圈对三小的评价，普遍建立在「不完整周期」的观察上，参考价值需打折 `[C]`

**当前班级数、学生数、教师数，公开渠道未获取**，这是本档案最主要的数据缺口。

### 2.4 校园环境

- 校园「环境优美，透着一种时尚的园林气息」（2021 年外校参访者描述）`[C]`
- 学校自述的办学策略是「**两手抓**」`[A]`：
  - 一手抓**校园外部文化建设**——营造「一草一木皆育人，每时每刻皆育人」的环境文化氛围
  - 一手抓**课堂课程文化建设**——「努力用活动、课程等培养学生的兴趣爱好，发展学生的特长」

> 「时尚的园林气息」这个描述值得留意——三小建校最晚，校园设计不必迁就早期保障房的统一形制，在建筑语汇上比丁小、二小更接近新建校的现代风格。但**具体占地面积、建筑面积未见公开数据**，无法与兄弟校做量化对比。`[C]`

## 三、办学特色

### 3.1 校训的特殊性：一句话的育人目标

三小的校训在南京公办小学中极为罕见——**它不是四个字或八个字的格言，而是一句完整的育人目标陈述** `[A]`：

> **「把男生培养成谦谦君子，把女生培养成大家闺秀」**

这个表述有几个值得分析的点：

1. **性别差异化培养**：明确按性别设定不同的培养形象，这在当前教育话语中属于少数派做法。学校的处理方式是把「君子/闺秀」解释为**行为规范与修养的共同标准**，而非能力差异——「谦谦」与「大家」都指向谦逊、有教养、有格局。
2. **与校风的呼应**：校风「律己　正人　善学」中的「正人」与「君子」同源，「律己」与「闺秀」的自我修养要求同源。
3. **与「新六艺」的接口**：传统「六艺」（礼、乐、射、御、书、数）本就是贵族/君子教育的内容体系，学校把「君子/闺秀」作为育人形象，再用「新六艺」作为实现路径，逻辑是闭环的。

> **客观提示**：这组表述在家长圈中存在不同看法。认同者认为它给了孩子清晰的行为标杆、有传统文化底蕴；质疑者认为按性别设定培养形象，与当代性别平等教育理念存在张力。**本档案如实记录原文，不作价值判断。** `[C]`

### 3.2 「正学」理念

- 教育理念为「**正学**」`[A]`
- 校方表述：「以『正学』作为核心教育理念，**点面结合构建发展空间**」（校长丁小刚在集团校长工作会议上的表述）`[A]`
- 学校对外宣传的栏目体系统一以「**正学丁三**」为前缀（如「正学丁三·教科研」「正学丁三·教学」「正学丁三·德育」「正学丁三·喜报」），形成稳定的品牌标识 `[A]`

### 3.3 「新六艺」课程：三小最系统的成果

这是三小最具分量的特色建设，2025—2026 年获评**栖霞区特色项目**。`[A]`

**① 政策依据** `[A]`

学校援引《深化新时代教育评价改革总体方案》（2020 年）中「完善德育评价、改进美育评价、强化体育评价、加强劳动教育评价」「增长知识见识，增强综合素质」的要求，作为课程设计的政策合法性来源。

**② 课程结构** `[A]`

| 新六艺 | 对应传统六艺 | 指向 |
|---|---|---|
| **达礼** | 礼 | 礼仪、行为规范 |
| **愉乐** | 乐 | 音乐、艺术 |
| **善射** | 射 | 体育、竞技 |
| **巧御** | 御 | 劳动、技艺 |
| **知书** | 书 | 书法、阅读、文化 |
| **数智** | 数 | 数学、思维、信息技术 |

**③ 空间与活动对应** `[A]`

| 空间 | 对应六艺 |
|---|---|
| 礼仪轩 | 礼（融考核于日常） |
| 乐苑 | 乐 |
| 射苑 | 射 |
| 御苑 | 御 |
| 书苑 | 书 |
| 数苑 | 数 |

**④ 评价体系（最值得注意的部分）** `[A]`

学校建立了「**日量化、周兑换、月评选、期记录、年展示**」五级评价模式，配套工具包括：

| 工具 | 功能 |
|---|---|
| 小翠竹评价表 | 日常量化 |
| 君子星卡 | 周兑换、激励 |
| 汇艺录 | 学期记录 |
| 君子印 | 年度最高荣誉（「彰其才，励其志」） |

> 「日—周—月—期—年」这套五级节奏，是南京小学特色课程评价中少见的完整设计。多数学校的特色课程止步于「开设了、有活动」，三小把评价链条一直做到了「年度印章授予」的仪式层。**这是三小在课程建设上最实的部分，也是最难被兄弟校复制部分。** `[B]`

**⑤ 品牌活动：「艺之独秀」嘉年华** `[A]`

每年六一儿童节举办，作为新六艺课程的集中展示平台。现场按「苑」分批展艺：

| 分场 | 展示内容 |
|---|---|
| 乐苑 | 载歌载舞，展艺术之韵 |
| 射苑 | 强身砺技，显体育之魂 |
| 御苑 | 巧手匠心，传劳作之美 |
| 书苑 | 挥毫泼墨，彰文化之蕴 |
| 数苑 | 挑战智慧，启思维之智 |
| 礼仪轩 | 融考核于日常，将文明素养内化于心、外化于行 |

活动尾声为「新六艺」考核表现突出的学生颁发「**君子印**」。`[A]`

**⑥ 获评过程** `[A]`

在栖霞区特色项目评选汇报中，由**丁小刚、张玉、常芸**三位老师组成汇报组，以「清晰的逻辑、详实的案例、生动的展示」阐述课程建构理念、实施路径与成果，最终「在评选中名列前茅」，获评栖霞区特色项目。

> 注意这三人中，丁小刚时任校长、张玉时任副校长（2026 年已任校长）、常芸为教科室副主任——**这是一次校长亲自下场做的课程申报**，而非交给中层代办。这个细节反映学校对这项特色的重视程度。`[A]`

### 3.4 「君子习礼」德育

| 层级 | 内容 |

| 三个板块 | 校园礼仪、家庭礼仪、社会礼仪 |
| 六个方面 | 礼仪概述、个人礼仪、社交礼仪、校园礼仪、文书礼仪、习俗礼仪 |

**② 校本教材**

学校自主开发《**小学生行为习惯养成教育校本教材**》，分**两册**。`[A]`

| 路径 | 做法 |

**⑤ 外部认可** `[A]`

《以礼育人，以德润心——基于「君子习礼」主题下小学德育课程创新案例分析》在**第六届长三角地区德育创新论坛**中被评为**优秀案例**。

> 长三角地区德育创新论坛是区域性德育领域的较高层级平台。一所建校不足五年的学校能在此获奖，说明「君子习礼」不是校内自娱，而是经过外部专业评审的。`[B]`

### 3.5 「云间农场」：劳动教育的校家社协同

三小另一项区级课题是《**「云间农场」：校家社协同育人视域下的新劳动教育实践**》（主持人秦志鹏），2024 年立项，2026 年 1 月完成中期论证。`[A]`

**核心设计** `[A]`：

| 维度 | 内容 |
|---|---|
| 主阵地 | 「云间农场」 |
| 资源整合 | 学校 + 家庭 + 社区 |
| 课程群 | 三大主线：「人与自然」「人与自我」「人与社会」 |
| 育人架构 | 「一核三维、四维一体」 |
| 家校形式 | 家长课堂、亲子劳动 |

> 「云间农场」这个名字暗示其形态可能不是地面农地（保障房片区土地紧张），而是**屋顶农场或立体种植**。这一推测未获官方确认，但符合「云间」的字面含义与片区实际条件。`[C]`

## 六、升学表现

### 6.1 对口初中

**南京师范大学附属中学丁家庄初级中学**（公办，栖霞区华银路25号）`[B]`

**比对依据**：

| 依据 | 内容 | 信度 |
|---|---|---|
| 2026 年初中施教区原文 | 「丁家庄保障房片区，银贡山庄，紫金北郡，熙景福苑。」 | A |
| 瑞丰园、秋韵园属性 | 属丁家庄保障房片区居住组团 | B |
| 万寿村社区属性 | 原行政村，地理上属丁家庄片区南缘 | C |
| 第三方整理表（2022） | 丁家庄第三小学 → 南师附中丁家庄初级中学（对应小区列「万寿村社区、瑞丰园社区、秋韵园社区」） | C |

**结论**：三小对口丁家庄初中，判断可靠，但同样属于「由『丁家庄保障房片区』这一概括性表述推导」而非逐条列举。**万寿村社区是其中最需要单独核实的单元**——它是原行政村，行政归属历史上与丁家庄片区不完全一致。`[C]`

### 6.2 三校出口的同一性

这是本档案需要强调的核心事实 `[A]`：

**丁家庄小学、丁家庄第二小学、丁家庄第三小学，三校对口同一所初中——南师附中丁家庄初级中学。**

含义有三：

1. **对口初中不构成三校之间的区分变量**。家长在丁小、二小、三小之间选择时，「哪个初中更好」这个问题不成立——答案相同。
2. **三校的出口差异只能来自生源与教学质量**，而非制度安排。
3. **三校实际上是一个「共同生源池」，在初中端汇合**。这使丁家庄初中能够获得相对稳定、规模可观的生源，也意味着三校的教学质量差异会在初中入学时被「抹平」一部分。

> **对家长的实际意义**：如果孩子最终要走对口路径，那么在三校之间纠结「哪所更好」的边际收益很低；真正值得比较的是**离家距离、班级规模、特色是否匹配孩子兴趣**这三项。`[C]`

### 6.3 小升初通道 `[A]`

1. **施教区对口直升**——丁家庄初中（主通道）
2. **热点公办初中电脑派位**——2026 年栖霞区参与派位的初中含南师附中丁家庄初级中学（15 人）、迈皋桥初级中学 29 中分校（15 人）、伯乐中学（20 人）等
3. **南外语言能力测评**——全市小学均可报名
4. **民办初中**——与热点公办、南外合计最多选 2 所

### 6.4 出口质量

**本档案不提供三小的升学率、南外录取人数**，原因 `[C]`：

1. 小学阶段无官方升学率口径
2. 南外不公布各小学生源明细
3. **三小 2025 年才产生首届毕业生**，可观测周期仅一年，任何「趋势判断」都缺乏样本
4. 丁家庄初中的中考表现，公开渠道无可核实数据

> 特别提示：网上若出现「丁家庄三小升学率 XX%」之类数字，几乎可以确定是编造或张冠李戴——**该校连一届完整周期的毕业生数据都未形成公开记录**。`[C]`

## 八、家长口碑与评价（`[C]`，需自行甄别）

**正面评价集中在**

- **课程体系完整**：新六艺六个维度 + 五个空间 + 五级评价 + 年度「君子印」，在南京小学中属少见的系统化设计
- **礼仪教育落地**：校本教材两册、礼仪护照集章、升旗仪式主题排布，不是口号
- **教师年轻有活力**：新建校教师队伍年轻，教研活动密度高（承办集团教研展示、课题论证）
- **校园新、环境好**：「透着一种时尚的园林气息」，硬件是四校中最新
- **离地铁最近**：毗邻 7 号线丁家庄站，通勤便利
- **小班可能性**：作为片区最年轻的学校，若生源未饱和，班额可能小于兄弟校（**未证实**）

**负面/争议评价集中在**

- **办学历史短、无完整周期**：2025 年才有首届毕业生，教学质量缺乏长周期验证
- **校训表述有争议**：「把男生培养成谦谦君子，把女生培养成大家闺秀」按性别设定培养形象，部分家长认为与性别平等理念存在张力
- **公开信息极少**：班级数、学生数、教师数、校园面积全部未公开，家长难以判断真实状况
- **骨干师资依赖集团输血**：自身造血能力尚未形成
- **荣誉积累薄**：与丁小（17 项）、二小（6 项）相比，三小的荣誉清单明显较短
- **「新六艺」的执行落差**：六艺覆盖六个领域，家长担心「样样都有、样样不精」

## 九、择校视角小结

**适合的家庭画像**

| 维度 | 判断 |
|---|---|
| 已购/已安置在万寿村、瑞丰园、秋韵园 | ★★★★★（唯一选项） |
| 认同传统文化与礼仪教育 | ★★★★★（君子习礼 + 新六艺 + 礼仪护照） |
| 看重课程体系完整度 | ★★★★★（六艺六维 + 五级评价，系统化程度四校最高） |
| 偏好新建校硬件与环境 | ★★★★☆（四校中最新的校园） |
| 依赖地铁通勤 | ★★★★☆（毗邻 7 号线丁家庄站） |
| 需要长周期办学验证 | ★★☆☆☆（2025 年才有首届毕业生） |
| 需要透明的办学数据做决策 | ★★☆☆☆（规模数据全部未公开） |

**关键决策变量**

1. **先排除两个小区**——**依云华府、燕华花园明确不在三小施教区**，这是三校中唯一的排除项，务必核对。
2. **万寿村社区需单独核实对口初中**——三小对口丁家庄初中是推导结论，万寿村作为原行政村是其中最不确定的单元。
3. **不要期待「出口差异」**——三小与丁小、二小对口同一所初中，出口无制度性差异。
4. **接受「新校不确定性」**——课程设计漂亮、教研活跃，但缺乏长周期验证，适合愿意与学校共同成长的家庭。
5. **校训表述需家庭自行判断**——「谦谦君子 / 大家闺秀」的性别差异化表述，是否契合家庭价值观，需父母自己权衡。
