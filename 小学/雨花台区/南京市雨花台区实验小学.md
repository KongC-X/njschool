## 二、基本情况

### 2.1 创办背景：一所「与雨花台共同成长」的老校

雨花台区实验小学**始建于 1946 年**，坐落于风景秀丽的**雨花台下**，迄今**已四易校名**。`[A]`

| 时间节点 | 事件 |
|---|---|
| 1946 年 | 学校创办 |
| 1987 年 | 被南京市列为首批办好的重点小学，命名为「南京市雨花台区实验小学」 |
| 1988 年 | 被国家教委表彰为**全国「德育先进校」** |
| 2000 年 | 被授予「**江苏省实验小学**」 |

> **解读**：1946 年建校、1987 年成为首批重点小学、2000 年成为省实验小学——这条时间线意味着学校**完整经历了新中国基础教育体制的三次关键认定**。它的「名校」身份不是近年的品牌运营，而是**制度性认定累积**的结果。这也解释了为什么在雨花台区家长圈中，雨花实小长期被视为「传统首选」。

### 2.2 教育集团：一校四址

2014 年，学校整合校内外教育资源，发挥实验小学优质教育资源的**辐射、示范和引领作用**，成立了**雨花实小教育集团**。`[A]`

**集团现为一校四址** `[A]`：

| 成员校 | 说明 |
|---|---|
| **南京市雨花台区实验小学** | 本部（本档案主体） |
| **雨花实小善水湾分校** | 教育集团成员校 |
| **雨花实小西善桥小学分校** | 教育集团成员校 |
| **雨花实小铁心桥小学分校** | 教育集团成员校 |

集团校长：**孔令松**。`[A]`

> **沿革提示（重要）**：**「一校四址」是集团今天的格局，而非 2014 年成立时的形态。** 集团成立后成员校陆续增加，其中**西善桥小学于 2019 年 5 月加入**雨花台区实验小学集团，此后才形成「本部 + 善水湾 + 西善桥 + 铁心桥」的四址格局。`[B]` 因此「2014 年成立、一校四址」这类连写容易造成误读——**2014 年是集团成立的年份，四址是其后逐步形成的现状**，两个时间点不应合并表述。

> **集团化办学的一句话理念** `[A]`：校长孔令松的表述是「我们以『生命化教育』的理念统领集团校，**各美其美，美美与共**，集团校所有成员互取长短，共同发展，办孩子喜欢的学校。」

> **提示**：集团化意味着**「雨花实小」这个招牌下有四所学校**。本部（雨花台区实验小学）与三个分校在**师资、生源、对口初中、办学成熟度**上均有差异。**择校时不宜只认招牌。**

## 三、办学特色

### 3.1 「生命化教育」的实践路径

学校把「生命」作为教育的第一性概念，形成一套完整的话语体系：

| 层级 | 表述 |
|---|---|
| 核心理念 | 生命如花　教育如雨 |
| 实践阐释 | 生命就如含苞待放的花朵，教育就像春风细雨，润物无声 |
| 办学理念 | 夯实生命成长基石 |
| 校训 | 让学习与生命同行 |
| 学校精神 | 生生不息 |
| 六个「生命化」维度 | 生命化德育、生命化课程与教学、生命化管理（三体系） |

**校长的表述** `[A]`：

> 「我们希望孩子在雨花实小的 6 年学习生涯中，能够具有『**雨花实小烙印**』，成为一名习惯良好、合作负责的学生；善于思考、主动探知的学生；体格健康、心智健全的学生；主动实践、积极创造的学生。」

### 3.2 「红色教育」——德育品牌（最突出的特色）

**红色教育是学校在全国范围内最具辨识度的德育品牌**，其根植于**雨花台的独有资源**。`[A]`

| 维度 | 内容 |
|---|---|
| 思想定位 | 以「红色教育」为核心的生命化德育体系 |
| 资源依托 | 雨花台这一得天独厚的德育资源 |
| 核心载体 | 「**红领巾志愿者服务队**」 |
| 实践形式 | 定期在**雨花台纪念馆为游人讲解** |
| 外部认可 | 被表彰为「**江苏省红领巾走进爱国主义教育基地『五小』活动优秀团队**」 |
| 外部认可 | 在全国少工委魅力少先队评比中获得「**魅力杯**」称号 |
| 社会影响 | 曾接待过胡锦涛总书记的夫人、特级教师**斯霞**等人 |
| 定位 | 已成为**江苏省学生志愿者活动的一面旗帜** |
| 媒体报道 | 多项德育活动先后被**中央电视台《新闻联播》《焦点访谈》**以及《新华日报》《中国少年报》等报道 |

> **解读**：把「区位资源（雨花台烈士陵园）」转化为「可持续的德育课程」，是雨花实小最成功的一件事。这种德育不是「讲一堂课」，而是**长期、定岗、面向社会的志愿服务**——学生在纪念馆为游人讲解，是把「红色教育」落到了**真实的公共场域**。这也是它能在全国范围内多次被国家级媒体关注的原因。

## 八、家长口碑与评价（`[C]`，需自行甄别）

**正面评价集中在**

- **老牌名校、底蕴深厚**：1946 年建校、1987 年首批重点小学、2000 年省实验小学，品牌认知度高。
- **德育品牌突出**：红色教育、红领巾志愿者服务队在雨花台纪念馆的长期服务，社会认可度高。
- **师资梯队成熟**：市、区以上骨干教师占 45%。
- **教研成果扎实**：南京市课堂改革先进集体、基础教育成果一等奖。
- **集团化办学**：一校四址，教育资源共享，「各美其美，美美与共」。
- **区位与自然环境**：坐落雨花台下，校园绿化好，是南京市教育系统优美校园。

**负面 / 争议评价集中在**

- **校园面积偏小**：12,279 ㎡ 占地、7,200 ㎡ 校舍（一期），在雨花台区公办小学中属中等偏小，**硬件空间不及新建校**。
- **集团内部的差异**：一校四址，本部与善水湾、西善桥、铁心桥三个分校在师资、生源、成熟度上有差异，**不宜用「雨花实小」一个标签一概而论**。
- **施教区含排除性条款**：雨花西路 3、5 号除外；明门公寓、德盈国际仅含住宅部分；淮风晓月府为过渡学区——**这些细节容易被忽略，导致误判**。
- **数据透明度**：特级 / 正高教师人数、南外录取、初中出口比例指标均未公开。
- **老城区生源结构**：施教区以老片区为主，与雨外小（宁南新区品质小区集中）在生源同质性上有差异。

| 重视德育与社会实践 | ★★★★★（红色教育 + 红领巾志愿者服务队） |

**关键决策变量**

1. **看本部还是分校**——「雨花实小」是**教育集团**，一校四址。本部（雨花台区实验小学）与善水湾、西善桥、铁心桥三个分校是**四所不同的学校**，**不要只认招牌**。
2. **逐条核对施教区，特别注意三处细节**——① 雨花西路 **3 号、5 号除外**；② 明门公寓、德盈国际**仅含住宅部分**（公寓类房产不在内）；③ **淮风晓月府为过渡学区**，归属可能调整。
3. **注意能仁里的精细切分**——**能仁里一村**属雨花实小，但**能仁里二村、三村**属共青团路小学。同一片区内的分界必须以官方原文为准。
4. **确认对口初中**——「雨花实小 → 雨花台初级中学」的推断基于施教区重合，**请以当年雨花台区教育局正式公示为准**。
5. **实地看硬件**——校园面积中等偏小，建议实地查看教室、体育馆、跑道（200 米）与功能室条件。
