## 二、基本情况

### 2.1 创办背景：一所「企业办学属地化」的典型样本

南京市梅山第二小学**创办于 1966 年**，**由梅山铁矿企业创建**，坐落于南京南郊**秦淮河畔**。`[A]`

**历史沿革** `[A]`：

| 时间 | 事件 |
|---|---|
| **1966 年** | 由**梅山铁矿企业**创办 |
| 长期 | 隶属于**上海宝钢梅山企业**（上海梅山冶金公司），属企业办学 |
| **2008 年 4 月 1 日** | 随**梅山教育属地化**，划归**南京市**管理 |
| 现属 | **南京市雨花台区教育局梅山总校** |

> **解读一：「梅山」为何会「属地化」**。要理解梅山二小，必须先理解「**梅山**」——梅山铁矿 / 梅山钢铁（上海宝钢梅山企业）是**上海在江苏南京境内的一块「飞地型」大型钢铁企业基地**。企业规模庞大、职工众多，因此**自办了一整套教育体系**（高中、初中、小学），且长期**在上海的教育管理体系内运行**（所以学校历史上曾被**上海市闸北区人民政府教育督导评估**、被**上海市教育委员会**德育督导评估）。**2008 年 4 月 1 日**，这套教育体系随「**企业剥离社会职能**」改革**整体移交南京市**，成为**雨花台区教育局梅山总校**。
>
> **解读二：梅山总校 = 一个「企业教育体系」的完整移交**。梅山总校**下辖五所基础教育机构**：**梅山高级中学、梅山第一中学、梅山第二中学、梅山第一小学、梅山第二小学**，形成**十二年一贯制衔接**的办学体系。**现任校长为展勇**（截至 2024 年）。这意味着梅山二小**不是孤立的一所小学，而是「梅山教育」这个整体中的一个学段环节**。`[A]`

### 2.2 「企业办学」的教育遗风

由于企业办学的特殊历史，梅山二小留下了几处**鲜明的「上海基因」与「企业基因」**：

| 现象 | 说明 | 信度 |
|---|---|---|
| 获**上海市**教育部门评估 | 经**上海市闸北区人民政府教育督导**评估为「区办学先进学校」；经**上海市教育委员会**德育督导评估为「上海市行为规范示范铜牌校」 | A |
| 获**上海市**荣誉 | 上海市德育工作先进集体、上海市行为规范示范学校 | A |
| 竞赛成绩带**上海烙印** | 多人次在参加**上海市教学比赛**中获得一等奖 | A |
| 企业式的**骨干梯队** | 曾设「梅山总校级骨干教师 / 学校级骨干教师 / 准骨干教师」三级梯队 | C |

> **解读**：一所**位于南京**的小学，荣誉体系里却长期带着**「上海市」**印记——这在南京小学中极为罕见，也**恰恰证明了梅山教育的「企业飞地」属性**。2008 年属地化后，学校**既承接了上海市基础教育的规范与要求（行规教育、行为规范示范），又融入了南京的教育体系**，形成一种**独特的气质**。

### 2.3 校园环境与办学规模

**校园环境** `[A]`：学校建有**校园计算机网络、闭路电视系统**，**25 个教室均配备教学多媒体设备**，所有办公室都配个人使用的计算机终端；拥有**计算机房**和**音乐、美术、舞蹈、劳技、自然实验、图书阅览**等专用教室，以及**创客教室**等设施。

**办学规模** `[A]`：

| 时点/口径 | 办学规模 | 信度 |
|---|---|---|
| 百度百科（现口径） | **24 个教学班、740 名学生、72 名在岗教工** | A |
| 360 百科口径 | 22 个教学班、743 名学生、在岗教工 49 人 | C |
| 2014 年下半年 | 一至五年级共 21 个教学班、600 多位学生 | C |
| 快懂百科早期口径 | 一至五年级共 25 个教学班、900 多位学生 | C |

> **解读**：从历史口径看，学校规模在**21—25 个班、600—900 名学生**之间波动，**整体呈「先缩小、后回升」的态势**——2014 年口径 21 个班 / 600 余人，近年口径回升到 22—24 个班 / 740 余人。这与**梅山矿区片区人口的回流与稳定**有关。目前**单年级约 4 个班、每班约 30 人**，属于**中等规模、班额适中**的公办小学。

### 2.4 片区背景：梅山街道与「梅山教育」格局

梅山二小所在的**梅山街道**，是雨花台区**西南部的企业型片区**。该片区的学校格局具有鲜明的**「梅山总校」色彩** `[A]`：

| 学校 | 学段 | 说明 |
|---|---|---|
| 南京市梅山高级中学 | 高中 | 2003 年创办，原梅山钢铁公司子弟学校，2008 年移交雨花台区政府 |
| 南京市梅山第一中学 | 初中 | 创建于 1971 年，位于梅山街道上怡新村 |
| **南京市梅山第二中学** | 初中 | 创办于 1976 年，位于西善桥梅山矿秦淮新河畔 |
| 南京市梅山第一小学 | 小学 | 服务梅山街道**生活区**部分 |
| **南京市梅山第二小学** | 小学 | 服务梅山街道**矿区**部分（本档案） |

> **关键区分：「一小 / 二小」对应「生活区 / 矿区」**。据《2026 年南京市雨花台区小学施教区范围》，**梅山第一小学**服务「梅山街道**所属生活区**部分：含中兴路社区、上怡新村社区、梅清苑社区」；**梅山第二小学**服务「梅山街道**矿区**部分：梅欣社区、梅岭社区（含梅苑小区）、上铁月和园」。`[A]` 家长在梅山片区择校时，**必须明确自己住的是「生活区」还是「矿区」**——这决定了孩子进一小还是二小。

## 三、办学特色

### 3.1 核心特色：「教育信息技术运用」+「行规教育」

梅山二小以「**教育信息技术运用**」和「**行规教育**」为办学特色。`[A]`

| 特色 | 内涵 | 支撑 |
|---|---|---|
| **教育信息技术运用** | 依托校园网络、班班通、多媒体教室、计算机房，深化信息技术与学科教学的融合 | 25 个教室配多媒体设备、计算机房、创客教室 |
| **行规教育** | 行为规范养成教育，塑造学生良好品行与习惯 | 曾获「上海市行为规范示范（铜牌校）」 |

> **解读**：
> - **「信息技术运用」是梅山二小的「老招牌」**。学校建校于 1966 年，却在**信息化教学上投入很早**——这源于**企业办学时期对办学条件的持续投入**（企业有钱、讲究标准化）。到 2008 年属地化时，学校已经建有**校园计算机网络、闭路电视系统、25 间多媒体教室**，这在当年的公办小学中属**领先水平**。
> - **「行规教育」承接上海市的教育传统**。「行为规范示范校」是上海基础教育的一项标志性评价，梅山二小把这一传统带入南京，成为学校德育的抓手。

### 3.2 「铁石梅花」文化与创客课程

学校以「**铁石梅花**」文化为引领，构建**科技与人文并重的课程体系** `[A]`：

| 维度 | 内容 | 信度 |
|---|---|---|
| 文化引领 | **「铁石梅花」文化**（寓意：铁石般的坚韧 + 梅花的品格） | A |
| 校训 | **铁石坚从磨砺出，梅花香自苦寒来**（传承梅花精神） | A |
| 课程取向 | **科技与人文并重** | A |
| 科技课程 | 开设**创客课程** | A |
| 评价机制 | 实施「**科技小梅花**」评价机制 | A |
| 精神内核 | 培育校园精神（**梅花精神**） | A |

> **解读：「铁石梅花」的文化设计很有巧思**。
> - **「铁石」**——直接对应梅山的**铁矿 / 钢铁企业属性**（铁、石）。
> - **「梅花」**——以梅花「凌寒独自开」的品格，比喻**在艰苦环境中磨砺成才**。
> - 校训「**铁石坚从磨砺出，梅花香自苦寒来**」，是把「钢铁锻造」与「梅花傲雪」两个意象**熔铸成一句育人箴言**——**用企业精神（钢铁）塑造学生品格（梅花）**。这是**企业办学文化遗产最生动的结晶**。
>
> 在课程落地上，「创客课程 + 科技小梅花评价」形成了**「教 — 学 — 评」闭环**，与学校「教育信息技术运用」的传统一脉相承。

## 四、师资力量

| 指标 | 数据 | 信度 |
|---|---|---|
| 教职工总数 | **72 人**（百度百科口径） | A |
| 教学班数 | 24 个 | A |
| 在校学生 | 740 人 | A |
| 师生比 | 约 **1:10**（据 72 名教工 / 740 名学生推算） | B |
| 另一口径教职工数 | 49 人（360 百科口径，对应 743 名学生，约 1:15） | C |
| 梅山总校级骨干教师 | **3 人**（2014 年口径） | C |
| 学校级骨干教师 | **6 人**（2014 年口径） | C |
| 准骨干教师 | **8 人**（2014 年口径） | C |
| 赛课成绩 | 多人次在参加**上海市教学比赛**中获得一等奖 | A |
| 特级教师 / 正高级教师 | **未获取**（学校未公开） | — |

> **解读**：**两套师资口径差异较大**——百度百科为「72 名在岗教工」，360 百科为「49 名在岗教工」，两者相差 23 人。结合 24 个班、740 名学生的规模，**若按 72 名教工计算，师生比约 1:10，属相当宽松**；若按 49 名，则约 1:15。**本档案不做单一结论**，但提示：**企业办学（尤其上海体系）通常编制较充裕，师生比优于同规模城区校的可能性较大**。
>
> **骨干梯队是「企业式」的**：梅山二小曾设「**梅山总校级骨干教师 / 学校级骨干教师 / 准骨干教师**」三级梯队——这种**多层级、可晋升的骨干体系**，带有明显的**企业人事管理色彩**，也说明学校**在教师培养上有制度化设计**。
>
> ⚠️ **口径提示**：上述骨干数据为 **2014 年口径**，**已距今十年以上**；学校**未公开最新的骨干结构、特级 / 正高级教师人数**。相关空白已列入第十节数据缺口。

## 五、招生与施教区

### 5.1 2026 年施教区范围（雨花台区教育局公示原文）`[A]`

**原文表述**：

> **梅山第二小学：梅山街道矿区部分：梅欣社区、梅岭社区（含梅苑小区）、上铁月和园。**

**施教区构成（逐条列出）** `[A]`：

| 类别 | 社区 / 小区 |
|---|---|
| **定位** | 梅山街道**矿区部分** |
| **列名社区** | **梅欣社区**、**梅岭社区（含梅苑小区）**、**上铁月和园** |

> **解读**：
> 1. **施教区以「矿区 / 生活区」划分**。梅山街道的居住聚落分为两类——**矿区**（梅山铁矿 / 钢铁生产的所在地）与**生活区**（职工生活配套）。**梅山二小服务「矿区部分」（梅欣社区、梅岭社区），梅山一小服务「生活区部分」（中兴路社区、上怡新村社区、梅清苑社区）**。这是梅山片区**最核心的择校分界线**。`[A]`
> 2. **「含梅苑小区」是一个关键细节**。梅岭社区**包含梅苑小区**——家长判断是否属于梅山二小，要**同时核对「社区名 + 小区名」**。
> 3. **「上铁月和园」的归属**。这个小区出现在**梅山二小**（小学）施教区中；在初中层面，据《2026 年雨花台区初中施教区范围》，**「上铁月和园」归金陵中学西善分校**，而**梅山第二中学**的施教区为「梅山街道矿区部分：梅欣社区、梅岭社区（含梅苑小区）」——**未含上铁月和园**。因此**上铁月和园的小学与初中对口关系需特别核实**（小学对口梅山二小，初中可能对口金中西善）。`[A]`
