# 南京致远外国语小学乐山路分校

## 三、在本教育集团中的位置

### ⭐ 本校的初中去向：加和关系

| 学校 | 西界 | 东界 | 南界 | 北界 |
|---|---|---|---|---|
| 致远分校 | 夹江 | 江东中路 | 河西大街 | 梦都大街 |
| **本校（乐山路分校）** | 夹江 | 江东中路 | **江山大街** | **河西大街** |
| **致远初级中学** | 夹江 | 江东中路 | 江山大街 | 梦都大街 |

**本校 + 致远分校 = 致远初级中学**，边界闭合、无剩余。详细推导见「南京致远外国语小学分校」档案。

> ⚠️ 标 `[B]`——建邺不写「对应××小学」。
>
> **一条旁证**：第三方入学平台标注本校「对口中学：南京市致远初级中学」，与文本推导一致。

### 「乐·善」：校训从两个音里长出来

本校校训是两个字：**乐·善**。校方给出的来历很具体：

> 「乐」和「善」**基于「乐山」二字之音**，源于《史记》「**乐善好施**」之意。

**三层解释**：

| 字 | 校方解释 |
|---|---|
| **乐** | 是**快乐的**，融入**音乐与艺术**的，源于**生活和实践**的 |
| **善** | 是**善良与完善**，是**品德和人格** |

配套：**教风「善教」、学风「享学」**。

> **为什么这套值得说**：校名「乐山路」是**地理**，「乐善」是**品德**——用一个**谐音**把地名转成了校训，**且《史记》的出处是真的**（「乐善好施」出自《史记·乐书》）。这比硬凑「××精神」巧妙得多。
>
> **对家长的实际含义**：校训指向**快乐 + 品德**，而非「拼搏」「卓越」。这个取向与本校「**没有小胖子、降低近视率**」的口号是一致的——**把身心健康放在学业之前**。

### ⭐ 体育：六个年级六项专项，这是本校最硬的差异化

本校的体育不是「有体育课」，而是**分年级的专项课程体系**（校方口径）：

| 年级 | 专项 |
|---|---|
| 一年级 | **足球** |
| 二年级 | **乒乓球** |
| 三年级 | **游泳** |
| 四年级 | **羽毛球** |
| 五年级 | **篮球** |
| 六年级 | **搏击操** |

**每周安排一节体育课进行专项学习。**

**配套的口号与成果**：

| 项目 | 内容 |
|---|---|
| 育人目标 | **体德为先，全面发展** |
| 办学口号 | **「体育为学科首席」**、**「没有小胖子，降低近视率」** |
| 足球成绩 | **「建邺杯」小学足球赛冠军** |
| 特色课程 | **嵌入式体育课程**、交通课程、电影课程、农食课程、**登山课程** |

> **为什么这一条比「足球特色校」有说服力得多**：
>
> - 多数学校的「体育特色」是**一个项目做全校**；本校是**六个年级六项**——**每个孩子六年要学六种运动**；
> - **「游泳」出现在课表里**，意味着有泳池或稳定的校外场地——这是**成本很高的安排**；
> - **「没有小胖子、降低近视率」这个口号是可以被验证的**（体检数据），不是空话。
>
> ⚠️ 但**本校的近视率、肥胖率实际数据未获取**——口号是否兑现，无法从公开资料判断。

### 校园：一批「会说话」的空间`[B]`

本校的校园设施**名称都很具体**，不像通用的「多功能厅」：

| 设施 | 名称 |
|---|---|
| 图书馆 | 「**书呆子莫来馆**」 |
| 朗读亭 | **荷兰风车**造型 |
| 阅读空间 | 「**阅读大巴**」「**乐山阅读火车**」 |
| 文化墙 | 「**山高人为峰**」 |
| 长廊 | 「**国旗长廊**」 |
| 站台 | 「**通往世界的站台**」 |
| 打卡点 | 「**遇见南京眼**」 |
| 教育基地 | 「**1937.12.13**」爱国主义教育基地 |
| 劳动/自然 | 楼顶「**乐山开心农场**」、「**校园萌宠动物园**」 |
| 阅览室 | **大巴阅览室** |

> **两个细节值得单独看**：
>
> 1. **「书呆子莫来馆」**——这个名字是**陶行知**的原话（他主张「不做书呆子」）。用在一个**图书馆**上，是有意的**反讽式命名**：图书馆不是让你变书呆子的地方。
> 2. **「1937.12.13」**——南京大屠杀死难者国家公祭日。作为**爱国主义教育基地**的名字，用日期而非文字，是**克制而沉重的处理**。校园紧邻「南京眼」，本校的「遇见南京眼」打卡点与这个教育基地形成了**同一片区的两种记忆**。

### 国际认证：Eco-schools「绿旗」`[B]`

**2024 年**，本校**首次参评**并通过国际 **Eco-schools** 项目认证，获「**绿旗**」荣誉——「**乐山开心农场**」项目成为**典型案例**。

> **Eco-schools 是什么**：由国际环境教育基金会（FEE）发起的全球性环境教育认证项目，「绿旗」是其最高等级。**南京小学里拿到的不多**。
>
> **对家长的实际含义**：这个认证评估的不只是「有没有种树」，而是**环境教育是否进入课程、是否有学生主导的行动**。本校以「开心农场」为案例通过，说明**农场是课程的一部分**，不是摆设。
