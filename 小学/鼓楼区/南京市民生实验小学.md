## 二、基本情况

### 2.1 两所铁路职工小学的合并

学校由**原上海铁路局南京铁路分局职工第一小学**（省级实验学校）与**职工第二小学**（省级模范学校）合并组建，属「强强联合」型整合。校名中的「民生」取自所在片区民生街。`[C]`

学校创建时间口径为 **1930 年**，是下关（现鼓楼）片区历史较长的小学之一。`[C]`

| 时间 | 事件 | 信度 |
|---|---|---|
| 1930 年 | 建校 | C |
| 其后 | 由铁一小、铁二小两所职工小学合并组建为民生实验小学 | C |
| 近年 | 获评江苏省实验学校、江苏省模范学校、全国少先队红旗大队 | C |

### 2.2 文化与硬件

学校提炼「**培根养心**」办学理念，建有培根苑、养心亭、尚学大道等主题文化设施；开发校本课程《微品德 微习惯 好人生》，推行「拇指点赞」奖章争章活动。`[C]`

占地 10,400 ㎡，配多媒体教室、自然实验室、美术室、舞蹈房、图书馆等 23 个功能室；曾获评南京市园林式校园。`[C]`

## 三、办学特色

### 3.1 小班化：最早的一批

学校在**省级实验小学中率先实施小班化教育**（对外表述为「这在省级实小中尚属第一家」），是南京市**小班化示范学校**。`[C]`

其小班化的两项着力点：`[C]`
- **环境**：班班有地板、形状多样的课桌、图书角，配电视与电脑
- **课堂**：小组活动作为基本组织形式，强调「发言机会多、实践时间多、合作机会多、个别辅导多、反馈信息多、认可欣赏多」

> 小班化是这所学校最有辨识度的标签，也是最需要实地验证的一项——资格认定与实际班额是两回事。

### 3.2 体育：乒乓球

学校乒乓队曾连续几届蝉联南京市少儿组亚军，是南京市体育特色学校。`[C]`

### 3.3 书法、航模与记者团

书法、航模、「小星星」记者培训已形成完整训练体系，在全国中小学生作文、摄影、绘画大赛中多人获奖。`[C]`

### 3.4 生态与研学

近年开展「守护长江微笑精灵」生态保护主题活动、雏鹰假日小队研学、清明「慎终追远」系列主题活动等。`[C]`

## 九、择校视角小结

| 维度 | 判断 |
|---|---|
| 居住地在民生街、工农新村、建宁路东段 | ★★★★★（施教区对口） |
| 看重小班化教学 | ★★★★☆（省级实小中最早一批，需核实当前班额） |
| 看重省级实验/模范学校资质 | ★★★★☆（双料，且为全国少先队红旗大队） |
| 孩子有乒乓、书法、航模兴趣 | ★★★★☆（三项都有传统积累） |
| 看重年轻化、创新课程 | ★★★☆☆（高级教师占 55%，队伍偏资深） |
| 希望走派位争取名额 | ☆☆☆☆☆（未列入 2026 年派位名单） |

**关键决策变量**

1. **小班化要实地验证**。这是它最核心的卖点，但资格认定 ≠ 当前班额。
2. **队伍资深化**。55% 高级教师意味着稳定与经验，但也意味着更新换代压力。
3. **没有派位通道**。非施教区家庭无法摇号进入。
4. **对口初中口径缺失**。这是本档案最大缺口。
5. **铁路系统办学渊源**。原铁一、铁二小的底子带来较强的管理规范性，但生源结构随片区变化较大。
