# 南京市鼓楼区第二实验小学

> **一句话定位**：始建于 **1985 年**的区属公办**江苏省省级实验小学**，历经「栖霞区实验小学 → 下关区第二实验小学 → 鼓楼区第二实验小学」三次更名，现为**鼓楼第二实验小学教育集团领衔校**；以「**博求教育**」为办学主张、以「学习习惯力」研究见长，坐落于中央门外东井村，2026 年以 **39 人** 计划参与鼓楼区热点公办小学电脑派位——**是当年鼓楼公办派位名额最多的一所**。

## 二、基本情况

### 2.1 创办背景

学校始建于 **1985 年**，最初名为「**南京市栖霞区实验小学**」。所在地现属鼓楼区小市街道，位于红山森林公园北侧，处鼓楼、玄武、栖霞三区交界。`[A]`

1995 年南京区划调整，学校划入下关区，更名为「**南京市下关区第二实验小学**」；2013 年下关区与鼓楼区合并，再次更名为「**南京市鼓楼区第二实验小学**」。`[A]`

也就是说，「二实小」这个名字在 1995 年之后才出现，此前它是栖霞区的实验小学。这一点在理解学校「城北老校」的定位时很关键——它的服务半径始终在中央门以北，而非鼓楼主城。`[A]`

### 2.2 历史沿革

| 时间 | 事件 | 信度 |
|---|---|---|
| 1985 年 | 建校，名「南京市栖霞区实验小学」 | A |
| 1995 年 | 区划调整至下关区，更名「南京市下关区第二实验小学」 | A |
| 2013 年 | 下关区、鼓楼区合并，更名「南京市鼓楼区第二实验小学」 | A |
| 2014 年 | 与砺志实验小学、小市中心小学组建**鼓楼第二实验小学教育集团** | A |
| 其后 | 五塘小学、建宁小学、旭日景城小学陆续加入集团 | A |
| 2013 年起 | 提出「学习习惯力」命题，持续十余年 | A |

### 2.3 集团化办学

2014 年，二实小与砺志实验小学、小市中心小学组建教育集团，此后五塘小学、建宁小学、旭日景城小学陆续加入，成为新鼓楼七大教育集团之一（后续口径为「十三个小学教育集团之一」）。二实小为**领衔校**。`[A]/[C]`

> **集团身份怎么看**：领衔校通常承担教研输出与师资调配的角色，对**本部**的直接增益有限，但对集团内**成员校**的教学规范有实际影响。判断一所成员校的水平，仍要回到它自身的师资与生源，不能按「集团牌子」整体估值。`[B]`

## 三、办学特色

### 3.1 博求教育

学校以「**博求教育**」为办学理念，培养目标为「具有博爱之心、博学之才的未来人」，校训口径有「协力共生，博求致远」。`[A]`

落地抓手是「**博求五园**」与「**学生五力**」：

| 五园 | 五力 |
|---|---|
| 健康生活校园 | 健康力 |
| 博爱感恩校园 | 生活力 |
| 经典书香校园 | 品格力 |
| 智慧创新校园 | 探索力 |
| 网络信息校园 | 创新力 |

### 3.2 「学习习惯力」研究

这是学校最具辨识度的教研标签。自 **2013 年**起，学校提出「学习习惯力」命题，聚焦学科特质与工具赋能，以课堂教学改革「12 个微行动」和儿童学习习惯力培育「工具箱」为技术路径。`[A]`

公开报道对其价值的表述是「让习惯培养从他律走向自律、让课堂教学从知识传授走向能力培塑」。`[B]`

> **需要冷静看待**：习惯力是**过程性指标**，不直接等于分数产出。这类教研品牌的真实效果，取决于执行密度与教师稳定性，外部无法从宣传口径判断。

### 3.3 书香校园

学校是南京市首批「**金陵书香校园**」，长期做阅读推广与亲子阅读，德育与家校共育是其对外表述较多的板块。`[A]`

## 九、择校视角小结

**适合的家庭画像**

| 维度 | 判断 |
|---|---|
| 居住地在东井村、小市村片区 | ★★★★★（施教区直接对口，通勤极短） |
| 鼓楼区户籍、想用派位争取一个公办名额 | ★★★★☆（39 人名额为全区公办最多） |
| 看重稳定的教研体系与阅读氛围 | ★★★★☆（习惯力研究十余年、书香校园） |
| 追求一线公办初中出口 | 待核实（对口初中口径为第三方，未见官方文件） |
| 看重校园硬件与场地 | ★★★☆☆（占地 2.1 万㎡，但建筑密度较高） |
| 追求全市层面的品牌溢价 | ★★☆☆☆（区域性强校，全市知名度有限） |

**关键决策变量**

1. **对口初中必须先核实**。这是本档案最大的信息缺口，也是决定出口的核心变量。第三方都说六十六中，但没有官方文件佐证。
2. **派位名额多不等于好摇**。39 人是计划数，官方不公布报名人数；名额多的学校往往也吸引更多报名。
3. **施教区极窄**。仅东井村、小市村两个片区，意味着学区房的适用范围很小，转手流动性需自行评估。
4. **三次更名的历史要理解清楚**。「栖霞区实验小学 → 下关区第二实验小学 → 鼓楼区第二实验小学」，校名变化不影响办学实体，但会影响老家长的认知与部分资料的可比性。
5. **与民办「鼓楼实验小学」不是一回事**。两者校名相似、性质相反（公办/民办）、位置相距较远，填报时注意区分。
