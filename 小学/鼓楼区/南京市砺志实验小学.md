## 二、基本情况

### 2.1 从「安怀新村小学」到省实验小学

学校始建于 **1986 年**，曾用名「安怀新村小学」，位于东井亭一带、毗邻红山森林动物园。`[C]`

2005 年年底，学校创建成为**江苏省实验小学**；2019 年入选江苏省智慧校园名单（小学组）。`[C]`

| 时间 | 事件 | 信度 |
|---|---|---|
| 1986 年 | 建校（曾名安怀新村小学） | C |
| 2000 年 | 从起始年级开设英语口语教学，形成办学特色 | C |
| 2003 年 | 参加教育部重点课题「科学教育—开发儿童少年潜能」实验研究 | C |
| 2005 年 | 获评**江苏省实验小学** | C |
| 2019 年 | 入选江苏省智慧校园（小学组） | C |
| 2024 年 | 信息科技教师入选鼓楼区教坛新秀支持计划 | C |

### 2.2 砺志教育

学校以「励」（砺）志为办学内核，定位「砺志特色发展」，倡导以「志」为核心，形成「砺志笃行、立志成才」的教育理念。`[C]`

校园环境围绕这一主题建设：读书凳、武术墙、励志横幅等，构成「独具特色的校园环境」。`[C]`

### 2.3 一文一武

学校以课题研究为载体，把**武术**引入教科研领域，确立市级课题「小学生练武砺志教育的研究」；同时长期抓阅读，最终形成「以读书、武术为核心的一文一武」特色文化。`[C]`

## 三、办学特色

### 3.1 武术

武术是学校最具辨识度的项目，其特殊之处在于把它做成了**市级教科研课题**而非单纯的运动队：一批师生在全国武术比赛中获一、二、三等奖。`[C]`

> 把体育项目做成课题，意味着它进入了课程与教学法层面，而不只是校队训练。这是判断「真特色」还是「招牌特色」的一个区分点。

### 3.2 英语口语

学校自 **2000 年**起从起始年级开设英语口语教学，是较早做低年级英语口语的公办小学之一。`[C]`

### 3.3 砺志大舞台

学校每年 5 月设「砺志大舞台」，让每名学生上台展示才艺。对外表述中，这一活动被认为帮助部分学生重建自信、带动了学业表现。`[C]`

### 3.4 心理与科学认读

学校是国家级小学生心理监护实验学校、南京市小学生心理研究实验学校、江苏省科学认读实验学校。`[C]`

## 九、择校视角小结

| 维度 | 判断 |
|---|---|
| 居住地在东井村、安怀村、黄家圩一带 | ★★★★★（施教区对口） |
| 孩子有武术兴趣或希望强身砺志 | ★★★★★（武术是市级课题，进了课程层） |
| 看重英语启蒙 | ★★★★☆（2000 年起起始年级口语教学） |
| 看重省实验小学资质 | ★★★☆☆（2005 年获评，属区内中游） |
| 追求已验证的升学出口 | 待核实（对口初中口径缺失） |
| 希望走派位争取名额 | ☆☆☆☆☆（未列入 2026 年派位名单） |

**关键决策变量**

1. **武术是真特色**。做成市级课题意味着有课程与教学法支撑，不是挂个校队牌子。
2. **没有派位通道**。非施教区家庭无法摇号进入。
3. **对口初中口径缺失**。这是本档案最大缺口。
4. **施教区混搭**。既有老旧小区，也有万科红郡、复地新都等新建盘，生源结构在变化中。
5. **英语口语的历史优势**。2000 年就开始做，但近十年各校普遍加强英语，这项先发优势是否还在，需实地了解。
