# 南京市滨江小学

> **一句话定位**：**1994 年**建校的**江苏省实验小学**，坐落扬子江畔、狮子山下，实行**一校两区**（金陵新四村校区为低年部、燕康园校区为中高年部）；以「**让每一个儿童都精彩**」为理念、以「**3+x 灵动课堂**」与 30 余种社团课程为教学骨架；**「小江豚」管乐团**多次获国内外展演大奖，连续多年被市教育局定为**南京市小学生「管乐一团」**——这是它最硬的招牌。

## 二、基本情况

### 2.1 沿革

学校 1994 年建校，位于原下关区金陵小区一带，现属鼓楼区宝塔桥街道辖区。`[C]`

| 时间 | 事件 | 信度 |
|---|---|---|
| 1994 年 | 建校 | C |
| 其后 | 创建南京市实验小学 → **江苏省实验小学** | C |
| 近年 | 获评南京市园林式校园、南京市依法治校示范学校、南京市智慧校园首批示范校 | C |

### 2.2 一校两区

学校现设两个校区，按学段分址：**金陵新四村校区为低年部**（1–3 年级），**燕康园校区为中高年部**（4–6 年级）。`[C]`

> 低高年级分址对双孩家庭影响直接——两个孩子的接送点可能不在同一处。这是择校时必须算的一笔账。

### 2.3 校园环境

学校以「自然流淌的诗意」为主题设计了十处景观（花径听风、绿荫方亭、沧波观鱼、青青子衿、乐海琴韵、青葵书屋等），获评南京市园林式校园。`[C]`

## 三、办学特色

### 3.1 「小江豚」管乐团

学校管乐团以「小江豚」命名，多次荣获国内外展演赛大奖，多次应邀参加大型演出，接待过澳大利亚、韩国及国内多地的教育代表团；**连续多年被南京市教育局确定为南京市小学生「管乐一团」**。`[C]`

> 在全市范围内被定为「一团」，意味着它在南京小学生管乐序列里处于第一位置。对管乐特长生家庭，这是**可绕过学区**的真实通道。

### 3.2 「3+x」灵动课堂

学校以南京市前瞻性教学改革项目《支持儿童差异性学习的课堂典型样态的研究》为引领，建构「3+x」灵动课堂，指向不同学习节奏儿童的分层支持。`[C]`

### 3.3 社团课程

开设国画、书法、诗歌、舞蹈、足球、创客、机器人等 30 余种社团活动课程。`[C]`

### 3.4 双语与信息

学校早期即以双语、信息、铜管、科普作为特色课程，是江苏省现代教育技术实验学校。`[C]`

## 九、择校视角小结

| 维度 | 判断 |
|---|---|
| 居住地在金陵小区、燕康园、上元门、燕江路一带 | ★★★★★（施教区覆盖面广） |
| 孩子学管乐、希望走艺术特长 | ★★★★★（市「管乐一团」，通道真实） |
| 看重省实验小学资质 | ★★★★☆（江苏省实验小学） |
| 看重校园环境 | ★★★★☆（十处景观、市级园林式校园） |
| 双孩家庭、接送人力紧张 | ★★★☆☆（低高年级分两个校区） |
| 希望走派位争取名额 | ☆☆☆☆☆（未列入 2026 年派位名单） |

**关键决策变量**

1. **管乐团是核心差异化价值**。市「管乐一团」的身份与小升初艺术特长的衔接，是这所学校最确定的一项。
2. **一校两区需要算接送账**。1–3 年级与 4–6 年级不同校区。
3. **没有派位通道**。非施教区家庭无法摇号进入。
4. **对口初中口径缺失**。这是本档案最大缺口，直接影响出口判断。
5. **学校历史较短（1994 年）**。文化积淀不及百年老校，但硬件与校园环境是新校优势。
