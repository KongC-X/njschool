## 二、基本情况

### 2.1 陶行知与这所学校

学校始建于 **1919 年**，是**陶行知先生创办的乡村学校之一**，前身「神策门小学」，由社会贤达王亮臣等人筹建。抗战期间校舍被炸毁，办学地址迁至和平门。`[C]`

**陶行知于 1928 年任该校校长**——这是它与南京其他小学最本质的区别：它不是「挂陶行知名字」，而是陶行知本人主持过校务的学校。`[C]`

| 时间 | 事件 | 信度 |
|---|---|---|
| 1919 年 | 创办，前身神策门小学 | C |
| 1928 年 | 陶行知任校长 | C |
| 抗战期间 | 校舍被炸毁，迁至和平门 | C |
| 解放后 | 更名东门街小学 | C |
| 1951–1952 年 | 台风刮倒校舍，两校合并，选址新建 | C |
| 特殊年代 | 命名为小市中心小学 | C |
| 1984 年 | 和燕路 12 号新校舍建成 | C |
| 2008 年 2 月 | 与原南京市小市小学合并 | C |
| 2019 年 | 建校一百周年；获评江苏省智慧校园 | C |

### 2.2 行知文化与「活的教育」

学校以「**行知文化**」立校，办学追求是「办新时代的**陶校**」，核心是实践陶行知「生活教育」理论——「生活就是教育」「社会是大的学校」「教学做合一」。`[B]/[C]`

其提炼的实践路径围绕一个「**活**」字：实施「活的管理」、研究「活的教学」、培育「活力教师」与「活力学生」，探索「活的教育」的**小市样本**。`[B]`

学校把校园愿景具象为三园：「快乐生活园」「炫美艺术园」「活动创造园」。`[B]`

## 三、办学特色

### 3.1 弦乐艺术

**弦乐**是学校对外展示中最突出的艺术项目，在百年校庆的特色教育现场展示中被单列。`[B]`

### 3.2 科技教育

学校为南京市科技教育相关认定校，科技教育是三项特色之一。`[C]`

### 3.3 体育

体育是学校对外表述中的第三项特色，与艺术、科技并列构成「艺体活动为载体」的办学路径。`[C]`

### 3.4 才艺启智、合作育人

「才艺启智，合作育人」是学校的特色化办学之路，配套「活力校园」建设。`[C]`

| 希望走派位争取名额 | ☆☆☆☆☆（未列入 2026 年派位名单） |

**关键决策变量**

1. **陶行知是这所学校的独家资产**。不是纪念性命名，而是本人主持过校务——这在择校时属于文化层面的加分项，但对升学无直接影响。
2. **一校两址要算接送账**。一、二、六年级在东校区，三、四、五年级在西校区。
3. **没有派位通道**。非施教区家庭无法摇号进入。
4. **对口初中口径缺失**。这是本档案最大缺口。
5. **师资数据过时**。现有公开数据无法反映当前水平，需实地了解。
