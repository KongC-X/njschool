## 二、基本情况

### 2.1 「建在图书馆里的学校」`[A]`

| 配置 | 数量 |
|---|---|
| 藏书馆 | 1 个 |
| 阅览室 | 2 间 |
| 阅读长廊 | 3 条 |
| 开放式书吧 | 6 个 |
| 班级图书角 | 41 个 |
| **总藏书** | **5 万余册** |
| 电子阅读器 | 6 台 + 1 个公用阅读 App |

配套开展「**慧学课堂**」行动研究，形成「**智生文化**」。

> **解读**：「41 个班级图书角 + 6 个开放式书吧 + 3 条阅读长廊」，这套配置的特点是**把书放到孩子走得到的地方**，而不是集中在一个借阅室。小学阶段阅读习惯的养成，**书与孩子的物理距离**是关键变量之一。
>
> 判断是否真落地，可以看两件事：书吧的书是否常换、孩子课间是否真的在那里。

### 2.2 ⭐ 足球：18 年，有奖牌有输送`[A]`

| 维度 | 数据 |
|---|---|
| 起点 | **2006 年**确定校园足球为办学特色 |
| 坚持 | **18 年** |
| 队伍 | 六支足球校队 + 四十一支足球班队，聘专业教练 |
| **国家级比赛冠军** | **1 个** |
| **省长杯冠军** | **2 个** |
| 省长杯亚军 | 6 个 |
| **市长杯冠军** | **4 个** |
| 市长杯亚军 | 11 个 |
| **输送队员** | 为国家和省市各级足球运动队输送**近百名** |
| 认定 | **全国足球特色学校**、**江苏省足球人才培养基地**、南京市校园足球重点学校 |
| 普及 | 全体师生共做**足球操**，开展足球趣味活动、建设校园足球文化 |

> **解读（本档案最有价值的一处）**：判断一所学校的足球是不是真特色，看三层——**普及（人人参与）、竞赛（有奖牌）、输送（有人才出口）**。
>
> 泰山小学三层都有：足球操 + 41 支班队是**普及**；省长杯冠军 2 个、市长杯冠军 4 个是**竞赛**；输送近百名队员、挂牌「**江苏省足球人才培养基地**」是**出口**。
>
> 「输送近百名」这个数字尤其关键——它说明学校的足球不是到小学毕业就断了，而是**有向上通道**。若孩子真有足球天赋，这是本片区最完整的通道之一。

| 项目 | 内容 |
|---|---|
| 办学理念 | **儿童立场** |
| 校训 | **灵如活水 稳如泰山** |
| 校风 | **己所不欲 勿施于人** |
| 教风 | 童心母爱 朴实扎实 |
| 学风 | 手脑并用 知行合一 |
| 团队精神 | 有自尊、有智慧、有行动、有温情 |

> **观察**：校训「灵如活水 稳如泰山」把地名（泰山）与教育期待（灵动 + 稳重）嵌在一起，是**有构思的**；校风用「己所不欲 勿施于人」这条**伦理底线**而非「团结勤奋」类套话，也算少见。

### 4.1 对口初中：南京市第一中学泰山分校`[A]`

**判定方式：初中施教区原文逐条覆盖本校施教区**

一中泰山分校 2026 年施教区原文包含：

> 泰山街道**天景社区（含浦东花园、泰山花苑、景福家园、浦东大厦等）**、**柳洲社区（含泰冯路泰山段等）**、大桥社区、**沧波门社区（含钟表材料厂宿舍、玫瑰花园、金泉泰来苑、玉澜府、华侨绿洲、泰西路 42 号、后河沿）**、**铁桥社区（含铁桥小区、新桥家园、新荣家园、泰福新寓、天然居、太平宝邸、弘阳爱上花园、毛纺厂宿舍等）**、泰山社区、**南农大工学院家属区**、铭人丽岛、**杏林北苑**、艾菲花园、盛泰嘉园……

**结论**：本校施教区的主要小区（金泉泰来苑、玉澜府、玫瑰花园、泰山花苑、铁桥小区、新桥家园、泰福新寓、杏林北苑、南农大工学院家属区）**逐一出现在初中施教区原文中**——属最直接的对应。

> **补充**：一中泰山分校施教区还覆盖鼎泰家园、山水云房、金城丽景、华侨城、中浦家园等（对应**鼎泰实验小学**与**力学海德北岸分校**片区）——**泰山东片多所小学共用该初中**。

### 4.2 小升初三类通道`[A]`
