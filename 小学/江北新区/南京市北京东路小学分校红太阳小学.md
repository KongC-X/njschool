> **一句话定位**：**2010 年 8 月**成立、**北京东路小学**品牌输出的公办小学；**东、西校区共 72 个教学班、2,733 名学生、191 名教职工**（含**特级教师 2 名**、市区骨干 30 余名）；在传承北小「**情智教育**」基础上提出「**沐浴阳光，情智育人**」，打造「**阳光教育**」品牌；2026 年招生 **10 个班**，对口初中为**南京江北新区浦口外国语学校**（施教区完全一致）。

## 二、基本情况

### 2.1 传承与再造：从「情智教育」到「阳光教育」`[A]`

| 层次 | 内容 |
|---|---|
| 母体传承 | 北京东路小学「**情智教育**」 |
| 本校理念 | 「**沐浴阳光，情智育人**」 |
| 培养目标 | 培养「**有情有智的阳光人**」 |
| 校风 | **自带光芒，温暖一片** |
| 教风 | **与儿童一起生长** |
| 学风 | 积极向上，快乐分享 |
| 品牌 | 「**阳光教育**」——精心设计**阳光课程体系** |
| 校园意象 | 「师生共同成长的温馨**阳光城**」 |

> **解读**：这是「名校分校」里少见的**做了二次提炼**的案例——不是照搬北小的「情智教育」，而是把它与本校气象结合成「**沐浴阳光，情智育人**」。
>
> 判断一次「品牌再造」是否成功，看表述是否自洽：**校风「自带光芒，温暖一片」、教风「与儿童一起生长」** 都在同一个隐喻系统里（阳光、生长），没有拼贴感。这比「传承 XX 理念 + 打造 YY 品牌」的生硬拼接要好。

### 2.2 规模与师资：一支年轻但高配的队伍`[A]`

| 指标 | 数据 |
|---|---|
| 教学班 | **72 个** |
| 学生 | **2,733 名** |
| 教职工 | **191 名** |
| **特级教师** | **2 名** |
| 市区学带、优青等骨干 | **30 余名** |
| 研究生学历 | 18 人 |
| 本科学历 | 168 人 |
| **平均年龄** | **31.2 岁** |

> **解读**：平均年龄 31.2 岁——这是一支**很年轻的队伍**。配上 2 名特级教师 + 30 余名市区骨干，结构上是「**少量资深引领 + 大量年轻执行**」。
>
> 优点：活力足、接受新方法快、师生代际距离小。
> 风险：**经验曲线尚未走完**，处理复杂学生问题（学习困难、行为问题、家校冲突）的成熟度需要时间。
>
> 平均班额约 38 人（2,733/72），属常规大校水平。

### 2.3 荣誉`[A]`

| 层级 | 内容 |
|---|---|
| 国家级/交流 | **海峡两岸戏曲与国学传承交流基地** |
| 省级 | 江苏省平安校园、**江苏省健康促进学校**、**江苏省艺术特色学校**、江苏省智慧校园 |
| 市级 | 南京市先进基层党组织、南京市文明校园、南京市绿色学校、**南京市小学艺术活动中心**、**南京少儿白局传承与实验基地** |
| 区级 | 江北新区师德先进集体、江北新区**首家校本研修示范单位** |

> **观察**：荣誉里**艺术类占了大头**——省艺术特色学校、市小学艺术活动中心、少儿白局传承基地、海峡两岸戏曲与国学交流基地。这说明「阳光教育」的落点之一在**传统艺术（戏曲、白局、国学）**，是有具体载体的。

## 四、对口初中与升学

> **核心提示**：小学阶段**不存在官方「升学率」指标**。出口质量由**对口初中的中考表现**间接体现。

### 4.1 对口初中：南京江北新区浦口外国语学校`[A]`

**判定方式：施教区逐字一致**

| 对比项 | 红太阳小学 | 浦口外国语学校（初中部）施教区原文 |
|---|---|---|
| 旭日上城 | ✔ | ✔ |
| 旭日家园 | ✔ | ✔ |

**结论**：两校施教区**仅含同样两个小区、完全一致**，属最清晰的一对一关系。

> **注意**：「浦口外国语学校」是**九年一贯制**（含小学部与初中部）。本校毕业生升入其**初中部**；而其**小学部**的施教区（旭日爱上城、旭日华庭）与本校不同。

### 4.2 小升初三类通道`[A]`

1. **施教区对口直升**（主渠道）：升入**浦口外国语学校**
2. **热点公办初中/民办初中电脑派位**：最多选报 2 所
3. **南外语言能力测评**：全市所有小学均可报名

> **关于南外录取数据**：**未检索到可靠、可核实的本校南外录取人数。** 本档案不提供未经证实的数字。

### 4.3 对口初中的定位

浦口外国语学校（初中部）2026 年招生 **26 个班**，是本批中规模最大的公办初中之一。

> ⚠️ **数据缺口**：**未检索到浦口外国语学校公开的、可核实的中考成绩数据**（四星达线率、普高率、均分、高分段）。本档案不臆造。

## 六、办学特色与荣誉

### 6.1 「阳光教育」体系`[A]`

理念「沐浴阳光，情智育人」；培养目标「有情有智的阳光人」；校风「自带光芒，温暖一片」；教风「与儿童一起生长」；学风「积极向上，快乐分享」；阳光课程体系；「温馨阳光城」校园意象。

### 6.2 传统艺术载体`[A]`

海峡两岸戏曲与国学传承交流基地、**南京少儿白局传承与实验基地**、南京市小学艺术活动中心、江苏省艺术特色学校。

> **解读**：「白局」是南京本土曲艺（用南京方言演唱），把它做成传承基地，属于**在地文化**方向的特色，与一般的「艺术社团」不同。

## 八、择校视角小结

**适合的家庭画像**

| 维度 | 判断 |
|---|---|
| 已购旭日上城或旭日家园 | ★★★★★（就近入学，路径最确定） |
| 看重特级教师配置 | ★★★★☆（2 名特级） |
| 孩子有戏曲、白局、国学等兴趣 | ★★★★★（市级传承基地） |
| 看重师资活力与年轻化 | ★★★★☆（平均 31.2 岁） |
| 偏好小班、资深团队 | ★★☆☆☆（大校、队伍年轻） |
| 非施教区、指望摇号 | ☆☆☆☆☆（非派位校） |

**关键决策变量**

1. **施教区只有两个小区**——旭日上城、旭日家园。`[A]`
2. **与浦口外国语学校小学部区分**——后者收旭日爱上城、旭日华庭；两校小学施教区不同，但**初中都去浦口外国语学校**。
3. **特级 2 名是硬指标**——在名校分校里属较高配置，且公开可查。
4. **艺术特色有在地性**——白局是南京方言曲艺，属于真正的地方文化传承，不是通用艺术社团。
5. **队伍年轻要看清**——平均 31.2 岁，活力足但处理复杂个案的经验还在积累。
