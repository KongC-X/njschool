## 二、基本情况

### 2.1 企业办学的完整样本`[A]`

南化四小的校史，是南京「企业办学 → 地方接收」这一历史进程的典型标本：

| 时间 | 事件 |
|---|---|
| **1961 年** | 建校，前身为**中石化南京化学集团有限公司职工子女第四小学**，属企业办学 |
| **1978 年** | 学校排球队成立，排球传统由此发端 |
| 1994 年 | 第一次较大规模改扩建 |
| **1997 年** | 原**南化五小并入** |
| 2002 年 | 创建南京市实验小学过程中，将一处卫生死角改造成校园小公园「**怡园**」 |
| **2004 年** | 因**企业学校剥离**，更名为「南京市南化第四小学」 |
| 2006 年 | 第二次较大规模改扩建 |
| **2009 年** | 从「怡园」出发，生发「**怡然校园文化**」办学标识，确立以「**养怡**」为核心的办学理念 |
| **2013 年** | 原**山潘街小学并入** |
| 2017 年 | 第三次较大规模改扩建 |
| **2022 年** | 组建**南京市南化第四小学教育集团** |
| **2024 年** | 集团新增**扬子第三小学、扬子第四小学**为成员校 |

> **解读**：三次合并（南化五小、山潘街小学）、三次改扩建、一次体制转轨（企业→地方），这所学校的体量是**靠整合而非新建**长出来的。这对家长的实际意义是：**校史长、社区根基深，但校区分散**（历史上曾「一校两区」：葛关路校区 + 山潘街校区），不同校区的条件与生源会有差异，不要只认一个校名。

### 2.2 ⭐ 「怡园」与「养怡」：一个校园景观长成的办学理念

这是南化四小最值得说的一处——**办学理念不是先写出来再找地方落地，而是从一个真实的空间里长出来的**。

| 环节 | 事实 |
|---|---|
| 空间起点 | 2002 年创建市实验小学时，把一处**卫生死角**改造成校园小公园，取名「**怡园**」 |
| 文化提炼 | 2009 年从「怡园」生发出「**怡然校园文化**」 |
| 理念内核 | 以「**养怡**」为核心——「养」是培育，「怡」是愉悦和悦 |
| 校训 | **怡然自得** |
| 校歌 | 《怡园之歌》 |
| 制度化 | 挂牌「**南京市怡然文化项目研究中心**」 |

> **解读**：这种「从景观到理念」的路径，比多数学校的「先定理念再造景观」更自洽。判断它是否真落地，可以看两个可核查的点：①学校有 70 多个学生社团 + 菜单式校本课程（覆盖全体学生）；②「怡然文化」被立项为市级项目研究中心。**有项目、有课程、有社团，说明理念不是墙上的字。**

### 2.3 排球：延续 47 年的传统项目`[A]`

| 维度 | 内容 |
|---|---|
| 起点 | **1978 年**成立校排球队 |
| 历史成绩 | 曾获**全国小学生排球赛冠军**，多次获市区小学生排球冠军 |
| 当前定位 | **南京市排球传统学校**；「南京市排球、击剑双项目阳光体育学校」 |
| 输送 | 曾为南京一中、梅园中学输送多名排球队员 |
| 教学转化 | 以排球为载体开展「小学生自主性选择」教育实践 |

> **解读**：47 年不断线，这在南京小学里不多见。更关键的是它的**转化方式**——不是「少数队员拿冠军」，而是**以排球为切入点做自主性选择教育，进而长出 70 多个社团**。这条链条说明体育特色被用来撬动课程结构，而不是只服务于竞赛成绩。

## 四、对口初中与升学

> **核心提示**：小学阶段**不存在官方「升学率」指标**。出口质量由**对口初中的中考表现**间接体现。

### 4.1 对口初中：南京市南化第二中学（主体）`[A]/[B]`

**判定方式：施教区小区逐条比对**

| 南化四小施教区小区 | 南化二中 | 扬子一中 |
|---|---|---|
| 南化九村 | ✔ | ✘ |
| 紫晶环球 | ✔ | ✘ |
| 山潘一村、二村 | ✔ | ✘ |
| **山潘三村、四村** | ✘ | **✔** |
| 水榭花苑 | ✔ | ✔（两校皆有） |
| 欣乐新村 | ✔ | ✘ |
| 欣城峰景 | ✔ | ✘ |
| 恒丰世家 | ✔ | ✘ |
| 时代芳华里、铭望府、暄玥府 | ✔ | ✘ |

**结论**：主体对应**南京市南化第二中学**（2026 年 8 个班）。但有两处需注意：

1. **山潘三村、山潘四村**在初中表中归**扬子第一中学**，不在南化二中；
2. **水榭花苑**同时出现在南化二中与扬子一中的施教区描述中——**同一小区被两校同时列出**，实际归属需以当年初中招生方案原文为准。

> ⚠️ **口径说明**：江北新区**未发布「小学—初中」一对一口径表**，本结论由**施教区小区比对**得出（`[B]` 级）。

### 4.2 小升初三类通道`[A]`

1. **施教区对口直升**（主渠道）
2. **热点公办初中/民办初中电脑派位**：最多选报 2 所
3. **南外语言能力测评**：全市所有小学均可报名

> **关于南外录取数据**：第三方资料称「三年内有 200 余名优秀学生被南外、南师附中、金中、育英二外、旭东中学等录取」（`[C]`），但**未拆分到具体学校、未标注年份区间**，无法核实。本档案不采用该数字作结论。

### 4.3 对口初中的定位

南化二中 2026 年招生 **8 个班**，施教区覆盖大厂街道新华路、园西路一带的南化家属区主体。

> ⚠️ **数据缺口**：**未检索到南京市南化第二中学公开的、可核实的中考成绩数据**（四星达线率、普高率、均分、高分段）。本档案不臆造。

## 六、办学特色

### 6.1 集团化办学：从总校到「四校联合体」`[A]`

| 时间 | 事件 |
|---|---|
| 2022 年 | 组建**南京市南化第四小学教育集团** |
| 2024 年 | 新增**扬子第三小学、扬子第四小学**为成员校 |

> **解读**：这一条对择校判断很关键——如果家庭在**扬子三小、扬子四小**的施教区内，孩子实际处于**南化四小教育集团**的教研与管理体系之中。集团内的教研统一、教师流动，是「普通校获得优质校方法」的主要途径。**看一所小学，要连它所属的集团一起看。**

### 6.2 排球与「自主性选择」教育`[A]`

- 1978 年起延续的排球传统，全国小学生排球赛冠军
- 以排球为载体，开展「小学生**自主性选择**」教育实践
- 从第一个「**蒲公英文学社团**」起，先后成立 **70 多个学生社团**，实现学生全覆盖
- 配套建设**菜单式校本课程**
- 足球：每周开设 1 节足球课（一二年级每周 4 节体育课、三至六年级 3 节）

### 6.3 荣誉与评价`[A]`

| 荣誉 | 备注 |
|---|---|
| 江苏省实验小学 | 核心资质 |
| 江苏省文明学校 / 省教育先进集体 | — |
| 江苏省健康促进金牌学校 | — |
| 南京市排球、击剑双项目阳光体育学校 | 特色认证 |

> **解读**：「连续十四年区级评估小学组特等奖」是这份档案里**最有说服力的持续表现指标**——它不是一次评比，而是十四年的稳定性。相比「某年拿了什么奖」，这种连续性更能反映管理的基本盘。

## 七、家长口碑与评价（`[C]`，需自行甄别）

**优势共识**

- **办学 60 余年，区域名校**，连续十四年区级评估小学组特等奖
- **省实验小学**，资质可核实
- **排球传统 47 年**，全国冠军，且转化为社团与课程体系
- **集团总校**，教研与管理有辐射能力（扬子三小、扬子四小为成员校）
- **社团覆盖全体**（70 多个社团 + 菜单式课程）
- **师资数据公开度较高**（区学科带头人 12、区优青 24）
- 公办零学费

**争议与关注点**

- ⚠️ **对口初中中考数据缺失**：南化二中的出口表现无公开可核实数据
- ⚠️ **施教区跨两所初中**：山潘三村、四村归扬子一中；水榭花苑两校同时列出
- ⚠️ **历史「一校两区」**：葛关路校区与山潘街校区的条件、生源有差异，需确认孩子实际就读校区
- ⚠️ **规模大**（57 个班、2,515 名学生），班级间差异需实地了解
- ⚠️ **「省特级 3 名」为累计培养数**，不等于当前在岗
- ⚠️ **校长姓名口径不一**（杨树亚 / 葛春庭）
- ⚠️ **不参加热点派位**：2026 年非派位校，非施教区家庭无入学通道

## 八、择校视角小结

**适合的家庭画像**

| 维度 | 判断 |
|---|---|
| 户籍房产在杨村二路、欣乐路以东一带 | ★★★★★（就近入学） |
| **孩子有排球、击剑等体育兴趣** | ★★★★★（47 年传统 + 市双项目阳光体育学校） |
| 看重社团与课程丰富度 | ★★★★★（70 多个社团 + 菜单式课程） |
| 大厂街道自住 | ★★★★★（生活配套成熟） |
| 追求确定的初中出口 | ★★☆☆☆（对口南化二中数据缺失） |
| 非施教区、指望摇号 | ★☆☆☆☆（2026 年非派位校） |
| 偏好小规模、高关注度 | ★★☆☆☆（57 个班属大校） |

**关键决策变量**

1. **先确认施教区四边界**——杨村二路与欣乐路以东、新华路以西、园西路与毕洼路以北、杨村路以南。范围涉及大厂街道多条道路，**购房前需精确核对门牌**。`[A]`
2. **确认实际就读校区**——学校历史上实行「一校两区」（葛关路、山潘街），校区条件与生源结构有差异。`[A]`
3. **初中学区要单独核对**——主体是南化二中，但**山潘三村、四村归扬子一中**；**水榭花苑同时被两校列出**。若家庭规划跨小学初中，这两处必须逐条确认。
4. **体育特长的通道是可预期的**——排球 47 年不断线、曾向南京一中与梅园中学输送队员。如果孩子真有排球或击剑天赋，这里不是「有兴趣班」，而是**有历史、有教练梯队、有输送记录**的项目。
5. **集团视角值得用上**——它是南化四小教育集团总校，扬子三小、扬子四小是成员校。选择时可以把这个体系一起考虑，而不只看单校。
