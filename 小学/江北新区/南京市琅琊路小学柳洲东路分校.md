## 二、基本情况

### 2.1 规模：本批最大的一所`[A]`

| 指标 | 数据 |
|---|---|
| 创建 | 2010 年 |
| 校区 | **一校两址**（南北两个校区） |
| 教学班 | **80 个** |
| 学生 | **3,100 余名** |
| 教师 | **200 余名** |
| 2026 年一年级 | **20 个班** |
| 位置 | 长江之畔、「一山三泉」之侧 |

> **解读**：80 个班、3,100 余名学生——这是**超大规模小学**（对比：本批另一所大校北小红太阳 72 班 2,733 人）。平均班额约 39 人。
>
> 大校的现实含义：**课程与社团资源丰富、教师储备厚、教研体系成熟**；但**班级间差异、个体关注度、校区差异**是需要单独确认的变量。这所学校的评价必须落到「**哪个校区、哪个年级部**」。

### 2.2 「若水」文化与生态教育：一套有国际认证的特色`[A]`

| 层次 | 内容 |
|---|---|
| 校训 | **上善若水** |
| 办学理念 | **办一所适合儿童本真的学校** |
| 校风 | 深思力行 |
| 教风 | 慎思敏行 |
| 学风 | 善思乐行 |
| 培养目标 | 培养新时代适合未来发展的、具有**民族情怀和国际视野**的儿童 |
| 特色 | 以「**若水**」文化为内涵的**生态教育** |

**生态教育的国际/国家认证**`[A]`：

| 认定 | 层级 |
|---|---|
| **国际生态学校** | 国际 |
| **联合国可持续发展教育项目实验学校** | 国际项目 |
| **全国生态文明特色学校** | 国家级 |
| **全国垃圾分类样板学校** | 国家级 |
| 江苏省优秀生态学校、省绿色学校、省节水型学校 | 省级 |

> **解读（这是本档案最有价值的一处）**：「生态教育」是南京小学里**最容易做成「环保主题活动」**的方向。但这所学校拿到的是**国际生态学校**与**联合国可持续发展教育项目实验学校**两项国际认定——这两项都有**课程、管理、社区参与、节能数据**等硬性评估指标，不是挂块牌子就能过。
>
> 换句话说：**它的生态教育是有外部标准验证过的**，这在特色宣传普遍空泛的环境里，可信度明显更高。

### 2.3 其他特色与荣誉`[A]`

- **中国书法特色学校**、江苏省硬笔书法培训基地
- 江苏省乒乓球运动协会**少儿培训基地**
- **全国童向朗读**、南京市体育特色学校、南京市智慧校园、南京市依法治校示范学校

> **观察**：书法（有省级培训基地）+ 乒乓（有省级培训基地）+ 朗读（有全国项目），三项都是**有实体培训基地或项目支撑**的，不是「开过课」。

## 四、对口初中与升学

> **核心提示**：小学阶段**不存在官方「升学率」指标**。出口质量由**对口初中的中考表现**间接体现。

### 4.1 对口初中：南京市第二十九中学柳洲东路分校`[A]`

**判定方式：施教区逐字一致**

| 对比项 | 琅小柳洲东路分校 | 29 中柳洲东路分校（施教区原文） |
|---|---|---|
| 北外滩水城 | ✔ | ✔ |
| 滨江雅园 | ✔ | ✔ |

**结论**：两校施教区**仅含同样两个小区、完全一致**，属最清晰的一对一关系，无例外。

> **特点**：这是本批中「小学—初中」施教区**重合度 100%** 的少数案例之一。家长不必逐小区核对，只要房产在北外滩水城或滨江雅园，路径就确定。

### 4.2 小升初三类通道`[A]`

1. **施教区对口直升**（主渠道）：升入**29 中柳洲东路分校**
2. **热点公办初中/民办初中电脑派位**：最多选报 2 所
3. **南外语言能力测评**：全市所有小学均可报名

> **关于南外录取数据**：**未检索到可靠、可核实的本校南外录取人数。** 本档案不提供未经证实的数字。

### 4.3 对口初中的定位

29 中柳洲东路分校 2026 年招生 **18 个班**，与本校 20 个班基本匹配，是桥北—沿江片区规模较大的公办初中之一。

> ⚠️ **数据缺口**：**未检索到29 中柳洲东路分校公开的、可核实的中考成绩数据**（四星达线率、普高率、均分、高分段）。本档案不臆造。

## 八、择校视角小结

**适合的家庭画像**

| 维度 | 判断 |
|---|---|
| 已购北外滩水城或滨江雅园 | ★★★★★（就近入学，路径最确定） |
| 看重生态/环境教育 | ★★★★★（两项国际认定） |
| 孩子有书法或乒乓兴趣 | ★★★★★（均有省级培训基地） |
| 追求超大校的资源丰富度 | ★★★★☆（80 班） |
| 偏好小班、高关注度 | ★☆☆☆☆（超大规模） |
| 非施教区、指望摇号 | ☆☆☆☆☆（非派位校） |

**关键决策变量**

1. **施教区只有两个小区**——北外滩水城、滨江雅园。`[A]`
2. **对口初中 100% 重合**——29 中柳洲东路分校施教区仅含同样两个小区，无需逐条核对。这是本批最省心的升学路径。
3. **生态教育有国际认证**——国际生态学校 + 联合国可持续发展教育项目实验学校，可信度高于一般「环保特色」。
4. **书法与乒乓有省级培训基地**——若孩子有这两项兴趣，是实打实的通道。
5. **分清校区**——一校两址（南北），条件与生源不同。
