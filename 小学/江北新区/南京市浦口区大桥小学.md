## 二、基本情况

### 2.1 位置与服务范围`[A]`

大桥小学位于永宁街道大桥片区，是本批中**农村校里规模较大**的一所（3 个班）。施教区覆盖五个片区，且每处都带「部分组」限定：

| 施教区 | 限定说明 |
|---|---|
| 大桥社区 | 整建制 |
| **联合社区** | **除部分组** |
| 青山社区 | 仅**原河北村** |
| **友联社区** | 仅**原友联村 1—7 组** |
| 高丽社区 | 整建制 |
| **大埝社区** | 仅 **1—5 组及 8、9 组** |

> **解读**：这份施教区是「拼块式」的——同一个社区被拆给不同小学。例如**青山社区**：原河北村归大桥小学，其余归车站小学；**友联社区**：1—7 组归大桥小学，8—12 组归车站小学；**大埝社区**：1—5 组及 8、9 组归大桥小学，6、7 组归永宁学校（小学部）。
>
> 这意味着**只看社区名完全无法判断归属**，必须查到组。

> **数据缺口（重要）**：本档案**未能检索到大桥小学的创办年份、办学历程、校训、办学理念、校园规模、师资结构与特色项目**。`[C]`

### 2.2 与三所小学的边界关系`[A]`

| 社区 | 归属小学 |
|---|---|
| 青山社区 **原河北村** | **大桥小学** |
| 青山社区（除原河北村） | 车站小学 |
| 友联社区 **1—7 组** | **大桥小学** |
| 友联社区 8—12 组、原双圩村 | 车站小学 |
| 大埝社区 **1—5 组及 8、9 组** | **大桥小学** |
| 大埝社区 6、7 组 | 永宁学校（小学部） |
| 联合社区（除部分组） | **大桥小学** |
| 联合社区（部分组） | 永宁小学 |

> **这是本批 17 所中最复杂的一组边界关系**——四所小学（大桥、车站、永宁、永宁学校）在同一片农村区域内交错划分，全部以「组」为单位。**购房或租房前，必须到所在社区核对具体组别。**

## 三、招生与施教区

### 3.1 2026 年施教区范围原文`[A]`

依据《南京江北新区（浦口区）2026 年小学招生入学工作实施方案》（宁新区管教发〔2026〕24 号）附件 1：

> 永宁街道**大桥社区**、**联合社区（除部分组）**、**青山社区（原河北村）**、**友联社区（原友联村 1—7 组）**、**高丽社区**、**大埝社区 1—5 组及 8、9 组**。

**招生计划：3 个班**。

> **边界提示（重点）**：本施教区由六个「拼块」组成，其中四处带组别限定——**只看社区名会判断错误**，必须核到组。与车站小学、永宁小学、永宁学校三校交界，详见 2.2 的对照表。

### 3.2 招生方式`[A]`

| 方式 | 说明 |

| **热点公办小学电脑派位** | ❌ 2026 年**未列入**江北新区（浦口区）热点公办小学派位名单 |

## 四、对口初中与升学

> **核心提示**：小学阶段**不存在官方「升学率」指标**。出口质量由**对口初中的中考表现**间接体现。

### 4.1 对口初中：南京市浦口区大桥中学`[A]`

**判定方式：施教区逐条比对——高度一致**

| 大桥小学施教区 | 大桥中学施教区原文 |
|---|---|
| 大桥社区 | ✔ |
| 联合社区（除部分组） | ✔（联合社区） |
| 高丽社区 | ✔ |
| 青山社区（原河北村） | ✔（青山社区（原河北村）） |
| 友联社区（原友联村 1—7 组） | ✔（原友联村 1-7 组） |
| 大埝社区 1—5 组及 8、9 组 | ✔（大埝社区（除 6-7 组）） |

**结论**：六项**逐一对应、完全一致**（中学表述为「除 6-7 组」，与小学「1—5 组及 8、9 组」等价），属最清晰的一对一关系。

> **补充**：大桥中学另含**东葛社区（原车站村）、友联社区 8—12 组、青山社区（除原河北村）、西葛社区、车站工区**——即**车站小学**的施教区。**大桥、车站两所小学共用同一所初中**。

### 4.2 小升初三类通道`[A]`

1. **施教区对口直升**（主渠道）：升入**大桥中学**
2. **热点公办初中/民办初中电脑派位**：最多选报 2 所
3. **南外语言能力测评**：全市所有小学均可报名

> **关于南外录取数据**：**未检索到可靠、可核实的本校南外录取人数。** 本档案不提供未经证实的数字。

### 4.3 对口初中的定位

大桥中学 2026 年招生 **3 个班**，同时承接**大桥小学与车站小学**两所小学的毕业生，属浦口区公办初中规模较小的一档。

> ⚠️ **数据缺口**：**未检索到大桥中学公开的、可核实的中考成绩数据**（四星达线率、普高率、均分、高分段）。本档案不臆造。

## 七、家长口碑与评价（`[C]`，需自行甄别）

**优势共识**

- **本批农村校中规模较大**（3 个班），课程与社团的展开条件相对稍好
- **对口初中完全一致**（大桥中学，六项逐条对应）
- **与车站小学共用同一所初中**，片区升学路径集中
- 位于永宁街道大桥片区，本地居住通勤便利
- 公办零学费

**争议与关注点**

- ⚠️ **施教区极度碎片化**：六个拼块、四处带组别限定，**判断归属难度最高**
- ⚠️ **公开信息极少**：校史、师资、特色、荣誉均无来源
- ⚠️ **对口初中中考数据缺失**，且规模仅 3 个班
- ⚠️ **位置偏远**（永宁街道大桥片区）
- ⚠️ **不参加热点派位**：非施教区家庭无入学通道
- ⚠️ **周边为农村地区**，生活与通勤配套有限

## 八、择校视角小结

**适合的家庭画像**

| 维度 | 判断 |
|---|---|
| 户籍房产在大桥、联合、高丽社区或指定村组 | ★★★★★（就近入学） |
| 希望小升初与熟悉同伴同校 | ★★★★☆（与车站小学共用大桥中学） |
| 偏好较小规模 | ★★★☆☆（3 个班） |
| 追求丰富的课程与社团 | ★★☆☆☆（农村校规模有限） |
| 追求可验证的办学质量 | ★☆☆☆☆（公开信息极少） |
| 非施教区、指望摇号 | ☆☆☆☆☆（非派位校） |

**关键决策变量**

1. **⭐ 必须核到「组」**——六个拼块、四处带组别限定。青山社区只有原河北村归本校，友联社区只有 1—7 组归本校，大埝社区只有 1—5 组及 8、9 组归本校。`[A]`
2. **这是本批边界最复杂的施教区**——与车站小学、永宁小学、永宁学校三校交错。**只看社区名一定判断错**。
3. **对口初中与车站小学相同**（大桥中学），两校毕业生同校升学。
4. **规模在农村校中较大**（3 个班），但绝对规模仍小。
5. **信息极少，必须到校了解**——校史、师资、特色均无公开材料。
