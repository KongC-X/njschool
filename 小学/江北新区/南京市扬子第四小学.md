# 南京市扬子第四小学

> **一句话定位**：**1992 年**创建（原**扬子石化有限责任公司第四小学**）、2004 年剥离到地方更名的**江苏省实验小学**；以「**思行致远**」为校训、以「**少年君子教育**」为核心理念，是南京少见的**以中华传统文化（国学）为办学主线**的公办小学，打造「**儒香校园**」；**2024 年成为南京市南化第四小学教育集团成员校**；2026 年招生仅 **2 个班**（本批 10 所中规模最小），对口初中为**南京市扬子第一中学**。

## 二、基本情况

### 2.1 从扬子石化四小到地方公办校`[A]`

| 时间 | 事件 |
|---|---|
| **1992 年 9 月** | 建校，原名**扬子石化有限责任公司第四小学**，原隶属扬子石化有限责任公司总校 |
| **2004 年** | **剥离到南京市化学工业园区**，更名为「南京市扬子第四小学」 |
| 2019 年 12 月 | 获评 **2016—2018 年度江苏省文明校园** |
| **2024 年** | 成为**南京市南化第四小学教育集团**成员校 |

> **解读**：与扬子二小（1986）、扬子三小（1987）一样，扬子四小也是**企业办学转制**而来。这类学校的共同特征是：**建校时间不长（30 余年）但社区根基深**，生源长期以扬子石化家属区为主，家庭结构稳定。三校同源但**各有独立施教区、对口中小学与办学主张**，不能混为一谈。

### 2.2 ⭐ 「少年君子教育」：一所把国学做成主线的公办小学`[A]`

这是扬子四小最不可替代的一点——它不是「开了几节国学课」，而是**把传统文化做成了学校文化的骨架**。

| 层次 | 具体内容 |
|---|---|
| 校训 | **思行致远** |
| 培养目标 | 培养具有「**现代本领、古典情怀、中华精神、国际视野**」的「**少年君子**」 |
| 办学理想 | 打造高品质精致化的**中华传统教育名校** |
| 校园形态 | 「学校幽雅、教师博雅、学生文雅」的「**儒香**」校园 |
| 办学载体 | 「**智慧校园**」+「**激潜课堂**」 |
| 学风 | 「如切如磋、如琢如磨」 |
| 教风 | 「不愤不启、不悱不发」 |
| 校风 | 「养正、启智、涵雅」 |

**四大国学课程系列**（贯穿环境课程、学科课程、活动课程）：

| 系列 | 内容 |
|---|---|
| 中华传统美德系列 | — |
| 中华传统节日系列 | — |
| **国学经典诵读系列** | 被列为**南京市经典诵读基地学校** |
| **亲自然二十四节气系列** | — |

> **解读**：这套体系的**完整度**值得注意——它有校训、有培养目标、有校园形态、有课堂模式、有四大课程系列，还有对应的市级认定（经典诵读基地）。**从理念到课程到认定是闭环的。**
>
> 「少年君子」这个提法也有具体所指：**现代本领 + 古典情怀 + 中华精神 + 国际视野**——四个维度里有两个是「现代/国际」，说明它**不是复古**，而是「用传统资源培养现代人」。这一点在评价这类学校时很关键。

### 2.3 集团归属`[A]`

2024 年加入**南京市南化第四小学教育集团**（总校南化四小：57 个班、2,515 名学生、连续十四年区级评估小学组特等奖）。集团机制包含教研统一、教师培训、考核协同。

## 三、招生与施教区

### 3.1 2026 年施教区范围原文`[A]`

依据《南京江北新区（浦口区）2026 年小学招生入学工作实施方案》（宁新区管教发〔2026〕24 号）附件 1：

> **扬村二路以西，葛关路以北，江北大道以东、平顶山路以南**区域；**平顶山路以北，冶山小铁路以西至江北大道以东**区域。含**扬子 14 至 21 村、绣景雅苑、中杨新村、宁馨家园、山胡、山许、油坊**等。

**招生计划：2 个班**——本批 10 所学校中**规模最小**。

> **边界提示**：施教区由两块组成，均以**扬村二路以西**为起点，与扬子二小（扬村三路以东）、扬子三小（扬村二路至扬村三路之间）**正好连成一片**——三校施教区在扬村路一带首尾相接，边界极易混淆，购房时必须逐条核对门牌。

### 3.2 招生方式`[A]`

| 方式 | 说明 |
|---|---|
| **施教区免试就近入学**（主渠道） | 户籍、房屋所有权证（不动产权证）、实际常住地「三者一致」 |
| **热点公办小学电脑派位** | ❌ 2026 年**未列入**江北新区（浦口区）热点公办小学派位名单 |

- **随迁子女**：由区教育局统筹安排，不参加派位

## 八、择校视角小结

**适合的家庭画像**

| 维度 | 判断 |
|---|---|
| 户籍房产在扬村二路以西、葛关路以北一带 | ★★★★★（就近入学） |
| **认同传统文化教育、希望孩子有国学底子** | ★★★★★（南京少见的国学主线公办校） |
| 看重校风与德育 | ★★★★★（省文明校园 + 少年君子教育） |
| 偏好极小规模、高关注度 | ★★★★★（2 个班，约 39 人/班） |
| 扬子生活区自住 | ★★★★★ |
| 追求科技/竞赛/国际课程路线 | ★★☆☆☆（虽省科技特色基地，但主线是国学） |
| 非施教区、指望摇号 | ★☆☆☆☆（非派位校） |

**关键决策变量**

1. **先确认施教区，尤其注意与扬子二小、三小的边界**——三校在扬村路一带首尾相接：扬子二小是「扬村三路以**东**」，扬子三小是「扬村二路以东、扬村三路以西」，扬子四小是「扬村二路以**西**」。**一条路之差就是另一所学校**，必须核对门牌。`[A]`
2. **国学不是点缀，是主轴**——如果家庭认同「古典情怀 + 中华精神」，这里是南京公办小学里最完整的一套；如果家庭目标是科技竞赛或国际路线，方向不匹配。这是**价值观选择**，不是质量高低。
3. **2 个班是硬约束**——规模小意味着关注度高，但也意味着社团少、同伴样本小。若孩子需要丰富的同伴环境或多元课程，需慎重。
4. **三个村组的初中归属要核实**——山胡、山许、油坊未在初中表中明确匹配。若房产在此，**必须提前向区教育局确认**。
5. **集团身份是新增变量**——2024 年加入南化四小教育集团，这是近两年的变化，值得纳入评估。
