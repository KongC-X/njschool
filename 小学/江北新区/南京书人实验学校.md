## 二、基本情况

### 2.1 学校性质与定位 `[A]`

南京书人实验学校是一所**十二年制民办学校**，涵盖**幼儿园、小学、初中**，并设有**高中部（含国际课程方向）**。学校坐落于江北新区（浦口区）**浦乌中路 199 号**，隶属「**书人教育**」品牌体系。`[A]`

> **解读**：书人实验是南京民办教育中**「培训基因 + 全日制办学」**的典型代表。"书人教育"是南京本土知名的教育培训品牌，其转型全日制办学的路径，既带来了**成熟的教研与应试方法积累**，也带来**「办学沉淀是否足够」的家长观望**。这是理解书人的第一把钥匙。

学校北侧与江北新区多个公办名校（金陵中学浦口分校、中华中学浦口城南中学等）同处一片教育快速增长的区域，**区域教育氛围浓厚**。`[C]`

### 2.2 学段完整度与体系内升学 `[A]`

书人最突出的结构特点是**学段完整**：

| 学段 | 说明 |
|---|---|
| 幼儿园 | 十二年制起点 |
| **小学** | **本档案对象** |
| 初中 | 2025 年中考总均分浦口区第一、四星率 100% |
| 高中（含国际课程） | 2026 年投档线 551 分；另设 **IGCSE / A-Level** 国际课程方向 |

> **解读（对小学部的意义）**：**学段完整 = 体系内升学通道完整**。书人小学部的学生，理论上可沿「小学 → 初中 → 高中（国内/国际）」的路径在**同一体系内**完成学业，这在南京民办中并不常见（多数民办只有小学+初中，或初中+高中）。对希望**减少学段转换风险**的家庭，这是结构性优势；但也要注意：**体系内升学是「兜底」选项，不等于「冲刺目标」**——书人高中部投档线 551 分、位次约 3.69 万名，属普通批次中段。`[A]`

### 2.3 办学理念与教学机制 `[A]`

| 维度 | 内容 |
|---|---|
| 教学机制 | 「**六统一 + 三套教学案**」——进度、教学案、课件、作业、辅导、评价**六统一**；**三套教学预案**适配不同层级学生 |
| 课堂模式 | 「**面批制 + 当堂清**」——当堂批改、当堂清障 |
| 班级规模 | **小班化教学**，精准辅导 |
| 课堂特色 | 强调**生生互动**——小组合作、学科演讲 |
| 体育合作 | 与**南京玄武体校**深度合作 |
| 体育项目 | **艺术体操、花样游泳**（省市级多项奖牌） |
| 国际课程 | 高中部 **IGCSE / A-Level** 方向 |
| 校本作业体系 | 语文「**小螺号**」、数学「**小帆船**」、英语「**小水手**」 |

> **判断**：「六统一 + 三套教学案」是书人最值得关注的教学机制。**「六统一」解决的是「同一教研标准」，「三套教学案」解决的是「同一班级内的分层适配」**——两者结合，指向的是**在均衡分班政策约束下，通过课内分层实现差异化教学**（见 3.3）。

### 2.4 校园设施 `[A]`

| 类别 | 设施 |
|---|---|
| 教学 | 各学年教室、功能教室、演讲厅、**DT 功能教室**、图书馆（藏书**超 2 万册**） |
| 艺术 | **大型多功能剧院、迷你剧院、黑匣子剧场**、艺术中心、音乐教室 |
| 运动 | **室内游泳馆**、羽毛球馆、排球馆、体育馆、**攀岩墙**、户外体育场、足球场、网球场 |

> **判断**：书人的硬件配置在其学费档位（23,500 元/学期）中属**较优水平**，尤其「**三剧场 + 恒温泳池 + 攀岩墙**」的组合，硬件亮点突出。对小学阶段而言，**剧场（戏剧教育）、游泳馆（生存技能）、攀岩墙（体能挑战）**这三项设施，分别对应三类可落地的课程形态，**硬件不是摆设而是课程支撑**。

## 三、办学特色

### 3.1 课程体系细节 `[A]`

| 层级 | 内容 |
|---|---|
| **小学基础** | 传统文化渗透，**游泳、书法、武术、国学经典积累** |
| **小学拓展** | **创意戏剧、海量阅读、科技思维**等特色定制课程 |
| 四年级以上 | 主学科**定制课程** |
| 每节课 | 保障 **15—20 分钟**独立思考与练习时间 |
| 校本作业 | 语文「小螺号」、数学「小帆船」、英语「小水手」三大校本作业体系 |

> **解读**：书人小学部的课程设计有三条**可辨识的逻辑**：
> 1. **传统文化 + 体育技能双线筑基**——「传统文化渗透、游泳、书法、武术、国学经典」构成了小学基础的骨架，其中**游泳被列为小学基础课程**，与其恒温泳池硬件呼应；
> 2. **拓展课程指向素养**——「创意戏剧」呼应三剧场硬件，「科技思维」呼应 DT 功能教室，「海量阅读」呼应 2 万册图书馆；
> 3. **保障课内练习时间**——「每节课保障 15—20 分钟独立思考与练习」是一条很具体的课堂纪律承诺，与其「当堂清」理念一致。`[A]`

### 3.2 社团与活动 `[A]`

学校社团课程覆盖**体育、艺术、劳动、科技、学科五大类，超 50 项**，具体包括：

> 板球、**攀岩**、**高尔夫**、国际象棋、舞蹈、爵士乐队、管弦乐团、合唱团、戏剧俱乐部、环保俱乐部、辩论、中国文化与国画、武术等。

> **判断**：书人小学部的社团在**广度（超 50 项）**与**独特性（板球、攀岩、高尔夫）**上均有辨识度。其中「板球」在南京小学中极为少见，属于**需要专项场地与师资**的项目；「攀岩」「高尔夫」同样对应硬件投入。这反映出书人在**非学科赛道的课程投入**是有实质支撑的，而非纸面列表。`[C]`

### 3.3 关于「分层教学」与均衡分班的说明 `[A]`

作为民办学校，书人受南京市义务教育阶段**均衡分班**要求约束：坚持阳光分班，严禁设立重点班、快慢班和实验班。`[A]`

> ⚠️ **家长圈口径**：书人教学推行「**三套教学案**」适配不同层级学生，并「结合小班化教学精准辅导」。这属于**课内分层教学机制**，而非固定行政班分层，**与均衡分班政策不冲突**。`[A]`

> **解读**：「均衡分班 + 课内分层」是当前南京民办校普遍采用的合规路径。对家长而言，关键不在于「有没有分层」，而在于**分层的具体操作是否透明、是否可追溯**——**建议在开放日中问清「三套教学案」如何分配、依据什么标准**。`[C]`

### 3.4 体育特色（与玄武体校合作）`[A]`

学校与**南京玄武体校深度合作**，打造**艺术体操、花样游泳**等特色体育项目，「斩获省市级多项奖牌」。社团课程中体育类占比显著（板球、攀岩、高尔夫、网球、足球、篮球、健美操等）。`[A]`

## 六、升学表现

> **核心提示**：**小学阶段不存在官方「升学率」指标**。书人小学部的出口价值，集中体现在**「本校一贯制衔接初中部」**这一通道，以及**其初中部的中考表现**所反映的体系培养能力。本节据此组织，不做任何小学「升学率」的虚构。

### 6.1 对口初中：书人实验学校初中部（本校直升）`[A]`

书人为**十二年制**学校，小学部生源渠道包括**本校小学部直升**。`[A]`

> **解读**：书人小学部的价值，**极大程度上来自其初中部的升学数据**（见 6.3）。2025 年初中部**总均分浦口区第一、四星率 100%、六大率约 70%**，是江北民办中升学表现最亮眼的一档。**「小学 → 初中」同体系衔接**，让家长在小学阶段即可获得一个**已被成绩验证的初中出口**——这是书人小学部的核心吸引力所在。`[C]`

### 6.2 关于「直升」的规则细节（民办一贯制通用规定）`[A]`

- 民办一贯制学校**初中部招生计划小于其小学部直升需求人数**时，仅面向校内采取电脑随机派位方式录取。
- 直升须在**规定时间内确认意愿**，逾期视为放弃。

> ⚠️ **提示**：上述为民办一贯制学校的**通用规则**。书人小学部**直升初中部的具体比例与意愿确认规则**，本档案**未检索到学校官方公示**，建议直接向学校确认。`[C]`
