## 二、基本情况

### 2.1 创办背景与区域角色

浦口实验小学是**桥北片区（泰山街道）基础教育的老牌支点**。其所处的**大华锦绣华城**板块是江北新区开发最早、人口最稠密的居住区之一，学校承担的正是这一超大型社区的基础教育配套职能。`[C]`

与江北新区近年大量「名校办分校」「新校速成」的路径不同，浦口实验小学的辨识度来自**办学年限长、社区口碑积累厚、生源结构稳定**三点。它不属于「引进型名校」（如琅琊路小学明发滨江分校、芳草园小学等鼓楼品牌输出校），而是**土生土长的区域公办主校**。`[C]`

> **解读**：在江北新区公办小学格局中，浦口实验小学与「引进型名校分校」形成两类不同范式——前者靠**时间与口碑**，后者靠**母体品牌**。家长在选择时，需先想清楚自己看重的是「成熟稳定的老校生态」还是「名校招牌与方法论」。

### 2.2 发展沿革与集团化架构 `[A]`

2026 年，浦口实验小学的组织形态为**「一校三址」**，即一个法人主体下的三个办学点：

| 办学点 | 施教区（2026 年官方口径） |
|---|---|
| **浦口实验小学（本部）** | 大华锦绣华城（临江苑、柳州苑、桂美颂、榴美颂、香榭美颂、香邑美颂、乐美颂、爱美颂、香鸢美颂、香醍美颂），浦园村（路）、浦建村、浦东村、浦东二村、津浦新村、新马路（不含浦欣家园、184、186、188 号）、浦铁一村（非铁路职工子女）、浦东路四号、六号、十八号（浦口电大门前小河为界）、南京电力环境保护科学研究所、铁道部南京煤炭设计院，桥工新村、迎江路（原桥北小学学区）、彩虹雅苑 |
| **浦口实验小学浦园路分校** | 江月府、锦汇苑、滨河御景、宜馨苑，宁港一、二村，大坝头 1—50 号，浦中路，浦铁二村，小柳一、三、四、六组，夹河六、七、九组，夹河新村，轮渡桥，河西街，河北街，浦熙雅园 |
| **浦口实验小学万江分校** | 万江共和小区（天和苑、地和苑、人和苑） |

> **重要沿革**：据 2026 年江北新区小学招生口径，**江北新区铁路小学自 2026 年秋季学期起停止招生，其原有职能由「浦口实验小学浦园路分校」代招**。`[B]` 这是浦口实验小学集团在本轮布局调整中的一次**实质扩容**，也说明其在桥北片区的「托底承接」角色被进一步强化。

### 2.3 校园环境

> **数据缺口**：学校**未公开**本部的占地面积、建筑面积、功能教室数量、运动场馆规模等硬件指标。`[C]` 已知信息为：学校为桥北片区老牌公办校，硬件配置符合江苏省义务教育学校标准化建设要求，并已建成使用「南京市义务教育招生信息化服务平台」相关的分班与学籍管理系统。`[A]`

### 2.4 集团化办学的意义

浦口实验小学的「一校三址」，本质上是**用同一套管理与教研体系覆盖桥北片区的多个小学位**。`[C]` 其价值与风险并存：

- **价值**：本部积累的教学管理经验可直接下沉至分校，避免新校「从零起步」；教师在同一法人主体内可流动，教研活动可统一组织。
- **风险**：三个办学点地理位置分散、生源结构不同、成熟度有落差，家长不能简单以「浦口实小」一个标签笼统判断。

> **提醒**：与金陵小学等集团校的情况类似，**「浦口实验小学」本部与浦园路分校、万江分校在师资成熟度、生源结构、硬件条件上均有差异**，择校时务必以**具体办学点**为单位评估。

### 3.3 均衡编班：2026 年最可核实的一项办学动作 `[A]`

2026 年，浦口实验小学发布了《南京江北新区浦口实验小学 2026 年新生均衡编班实施方案》，是本档案能检索到的**信度最高、细节最完整**的学校文件之一。其要点包括：

| 环节 | 具体做法 |
|---|---|
| 组织领导 | 成立以**胡琳书记**为组长的均衡分班工作领导小组，**教学副校长邱婷**任副组长并具体负责 |
| 分班工具 | 采用「义务教育招生信息化服务平台内的分班工具」随机分班 |
| 均衡标准 | 确保**各班级人数大体相同、男女生比例大体相当** |
| 师资配置 | 按教师专业能力、管理经验、年龄结构**均衡组建团队**，并以平台工具**随机配班** |
| 信息公开 | 官网提前公开分班方案；分班完成后公示**分班方案、学生名册、任课教师团队** |
| 纪律 | 分班结果张榜公布后**不再更动，严禁校内调班**；学生中途不得调班 |

> **解读**：这份方案的价值在于，它把「均衡分班」从口号变成了**可核查的流程**——用平台工具随机分班、公开教师团队、承诺不调班。对担心「择班择师」的大校家长而言，这是有实际意义的制度保障。但也需注意：**均衡分班解决的是「起点公平」，不等于「班与班之间教学质量完全一致」**，实际效果仍取决于师资团队的均衡程度。

## 八、家长口碑与评价（`[C]`，需自行甄别）

**优势共识**

- **老牌公办，口碑积累厚**：桥北片区办学时间最长、社区认可度最高的公办小学之一
- **生源稳定**：施教区以成熟社区（大华锦绣华城）为主，家庭结构稳定，非「生源暴涨型」新校
- **管理规范**：2026 年均衡编班方案公开透明，承诺不调班，制度约束明确
- **地段成熟**：桥北片区生活配套完善，通勤与居住便利
- **公办零学费**
- **集团化承接能力强**：代招铁路小学原施教区，说明其被主管部门视为片区「稳盘」力量

**争议与关注点**

- ⚠️ **公开信息透明度偏低**：师资数据、硬件指标、荣誉清单、中考对口表现等**几乎均未公开**

- ⚠️ **「一校三址」差异**：本部与浦园路分校、万江分校在生源结构、成熟度上存在差异，不宜用一个标签判断

- ⚠️ **名称易混淆**：与浦口区江浦街道的「南京市浦口区实验小学」为两所不同学校

## 九、择校视角小结

**适合的家庭画像**

| 维度 | 判断 |
|---|---|
| 已在大华锦绣华城等施教区有房产 | ★★★★★（就近入学，成本最优） |
| 看重老校口碑与稳定的社区生态 | ★★★★★ |
| 重视办学规范与公平（均衡分班） | ★★★★☆（制度公开、承诺不调班） |
| 桥北片区自住刚需 | ★★★★★（生活配套成熟） |
| 追求对口初中「确定的高出口」 | ★★☆☆☆（对口初中公开数据缺失） |
| 希望有热点公办摇号机会 | ★☆☆☆☆（2026 年未列入派位名单） |
| 重视学校信息透明度 | ★★☆☆☆（公开信息少） |
| 追求新建校硬件条件 | ★★☆☆☆（老校区） |

**关键决策变量**

1. **先确认施教区归属**——浦口实验小学是严格按施教区招生的公办校，**核心施教区为「大华锦绣华城」十一个「美颂」苑**。讨论「好不好」之前，先确认房产与户籍是否落在施教区内（「三一致」）。`[A]`
2. **区分「一校三址」**——本部、浦园路分校、万江分校是**三个不同的办学点**，师资、生源、成熟度有别。**不要只认「浦口实小」四个字。**
3. **对口初中是关键变量**——浦口实小对口**南京江北新区实验初级中学**（原南京市河西中学），但**该校公开中考数据缺失**。建议通过教育部门、在校家长等多渠道了解其真实出口表现。
4. **不要误信「有摇号名额」的说法**——**2026 年浦口实验小学并未列入江北新区热点公办小学派位名单**，这一条已由官方文件核对确认。`[A]`
5. **核实名称**——「南京江北新区浦口实验小学」（桥北，本档案对象）与「南京市浦口区实验小学」（江浦，文昌路 2 号）是两所学校，搜索资料时极易混淆。
