# 静态托管方案对比与迁移建议

> 调研日期：2026-10-31　|　适用项目：南京中小学档案站（560 页纯静态，24MB）
> 结论基于公开文档与社区实测，**额度政策变动频繁，落地前请以官方当期文档为准**

---

## 一、结论先行

**推荐路径：Cloudflare Pages 先兜底（当天可用），同时启动 ICP 备案（3–22 工作日），备案下来再切 EdgeOne 国内节点。**

理由：

| 阶段 | 动作 | 解决什么 | 耗时 |
|---|---|---|---|
| 第 1 步 | GitHub Pages → **Cloudflare Pages** | 从"打不开"变成"能打开"（国内不稳但可用） | **半天** |
| 第 2 步 | 注册域名 + 提交 ICP 备案 | 拿到国内合法入口 | 3–22 工作日 |
| 第 3 步 | 备案下来接 **EdgeOne 国内节点**（或阿里云 ESA） | 家长秒开 | 1–2 天 |

**不推荐一步到位直接上国内节点**，因为备案周期不可控（江苏个人备案承诺 15 工作日，但教育类内容存在被要求补材料甚至前置审批的风险），期间站点会一直处于无入口状态。

---

## 二、核心事实：备案是绕不过去的分水岭

这是所有讨论的前提，先说清楚。

**没有备案 = 只能用境外节点 = 国内访问质量取决于跨境线路。**

各家"免备案"的说法都是真的，但代价是：走香港/日本/新加坡节点，首字节延迟通常 150–400ms，资源多的时候体验明显发涩。而 `github.io` 的情况更糟——**它不只是慢，是经常直接 DNS 污染打不开**。

| 情况 | 国内家长能否正常访问 |
|---|---|
| GitHub Pages | ❌ 大概率打不开 |
| Cloudflare Pages（免备案） | ⚠️ 能打开，偏慢 |
| EdgeOne 免费默认域名 | ❌ 大陆只能看 3 小时有效的预览链接 |
| EdgeOne 海外区（绑自己域名） | ⚠️ 能打开，偏慢 |
| EdgeOne 国内区（备案） | ✅ 快 |
| 阿里云 ESA 免费版 | ❌ 默认不含大陆节点，需发帖解锁 |

## 三、方案明细对比

### 3.1 免费额度（2026-10 核实）

| 平台 | 带宽/流量 | 构建 | 存储 | 项目/域名 | 备案 |
|---|---|---|---|---|---|
| **GitHub Pages**（现状） | 100GB/月（软限） | 每小时 10 次 | 1GB | 1 仓库 1 站 | 免 |
| **Cloudflare Pages** | **不限** | 500 次/月 | — | 不限 | 免 |
| **EdgeOne Pages**（现名 EdgeOne Makers） | **不限流量与请求** | 500 次/月，并发 1，单次≤20 分钟 | 5GB，单文件 25MB | 40 个 / 200 域名 | 国内节点需 |
| **阿里云 ESA 免费版** | 不限流量，**峰值 5Mbps** | — | — | — | 国内节点需 |
| 腾讯云 CloudBase 静态托管 | 10GB/月 | — | 5GB | — | 需 |
| Gitee Pages | 无限页面 | — | — | — | 需实名，内容审核严 |

### 3.2 对本项目的实际影响

站点 24MB / 560 页，单页 38–69KB。**任何一家的免费额度都远超需求**——真正的瓶颈不是额度，是**国内可达性**和**是否备案**。

5Mbps 峰值带宽（阿里云 ESA 免费版）≈ 625KB/s，单页 60KB 约 0.1 秒，够用。但如果以后加图片墙会吃紧。

### 3.3 迁移成本

这是好消息：**站点本身几乎不用改**，工作量全在 CI。

| 平台 | 迁移工作量 | 说明 |
|---|---|---|
| Cloudflare Pages | **小** | 保留现有 GitHub Actions 构建，末尾加一步 `wrangler pages deploy site` 即可，不必把 Python 环境搬到 CF |
| EdgeOne | **小** | 同上，用 CLI 或 Git 连接；Git 连接需在其构建环境里装 Python |
| 阿里云 ESA / OSS | 中大 | 需要配置 OSS Bucket + CDN + 回源，没有 Pages 那种一键部署 |

**关键建议：不要让托管平台自己构建。** 本项目依赖 Python 3.12 + `requirements.txt`（markdown / openpyxl）+ `make site`，各家构建环境的 Python 版本和依赖缓存策略都不一样。继续用 GitHub Actions 构建、只把 `site/` 目录上传，是最稳的做法：

```
GitHub Actions: 校验 → 构建 → 质量闸门 → 上传到托管平台
```

这样换托管方只是换最后一步的上传命令，前面全不动。

## 四、ICP 备案的现实成本（江苏，个人）

### 4.1 流程与周期

| 环节 | 时长 |
|---|---|
| 接入商初审 | 1–2 工作日 |
| 工信部短信核验 | 约 5 分钟 |
| 管局审核 | 最长 20 工作日（江苏承诺办结 15） |
| **合计** | **3–22 工作日** |

### 4.2 材料（个人）

- 身份证正反面原件彩色照片（有效期需 > 1 个月）
- 人脸核验（江苏已全面电子化，接入商小程序内完成）
- 域名持有者必须与主办人**姓名完全一致**（域名先做实名认证）
- 非江苏户籍需提供居住证
- **需要先购买云产品拿到"备案服务码"**——这是硬门槛，光有域名备不了案

### 4.3 ⚠️ 一个必须提前想清楚的风险

备案审核会看网站内容。搜索到的公开信息里明确提到：

> 涉及**教育、培训招生信息**的，需提供**办学许可证或教育部门备案证明**。

你的站是"学校档案 + 择校信息"，不是培训机构招生页，理论上属于信息汇编。但审核人员怎么归类，取决于**你填的网站名称和内容描述**：

- ❌ 别写「南京择校指南」「升学咨询」「招生信息汇总」——直接触发教育类前置审批联想
- ✅ 建议写「南京中小学公开信息档案」「学校公开资料汇编」，并说明内容来源为政府与学校公开渠道

这一条如果踩错，备案会被反复驳回，周期从 2 周变成 2 个月。

### 4.4 另一条路：不备案，接受境外节点

如果不想折腾备案，Cloudflare Pages 是可以长期用的：**无限带宽、免备案、免费**。代价是国内访问偏慢，但**比现在完全打不开是质变**。

## 五、待你确认的三个问题

**1. 家长主要在什么网络环境下访问？**
如果主要是手机流量/家庭宽带，且没有代理习惯 —— 备案是唯一解。

**2. 这个站是个人性质还是机构性质？**
- 个人：备案用身份证，网站名称要避开"教育""招生""咨询"等词
- 学校/机构：需要办学许可证或单位证明，但备案主体更"正规"，后期也更好扩展

**3. 是否愿意接受 2–4 周的空窗期？**
如果愿意，直接走"注册域名 → 备案 → EdgeOne 国内节点"，一步到位。
如果不愿意，先上 Cloudflare Pages，备案并行推进。

## 六、我建议的执行顺序

```
今天        ① Cloudflare Pages 上线（半天）
              用现有 GitHub Actions 构建 + wrangler 上传
              拿到 xxx.pages.dev 域名，先能用

本周        ② 注册域名（.cn 或 .com，50–80 元/年）
              域名实名认证 3 天

第 2 周     ③ 提交 ICP 备案（个人，江苏）
              同时买最低配云产品拿备案服务码

第 3–5 周   ④ 备案通过 → 接 EdgeOne 国内节点
              域名 CNAME 切过去，Cloudflare 保留作海外兜底
```

第 ① 步我可以直接做完（CI 改造 + 部署验证），你只需要去 Cloudflare 注册账号并在 GitHub 里授权。

第 ② ③ 步只能你本人操作（实名、人脸核验）。

## 七、附：不推荐但值得知道的选项

| 方案 | 为什么不推荐 |
|---|---|
| Vercel | 默认节点在美西，国内访问一般；免费版 100GB 带宽比 CF 少；对本项目无优势 |
| Netlify | 免费额度用"积分"折算，比 CF 保守，超出会暂停 |
| Gitee Pages | 需实名 + 内容审核，且历史上多次暂停服务，不适合做长期入口 |
| 腾讯云 CloudBase 静态托管 | 需要备案，且免费额度（10GB/月流量）远小于 EdgeOne |
| 自建服务器 + 宝塔 | 维护成本高，静态站没必要 |
