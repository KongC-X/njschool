# 南京市临江高级中学

> **一句话定位**：江宁区公办**江苏省四星级普通高中**，前身为 1956 年创办的江宁镇初级中学，2007 年迁址更名「临江高级中学」，2020 年与**秣陵中学**合并；以「**为每位学生的厚实人生奠基**」为办学理念，**艺体特色**鲜明；2026 年第一批次投档线 **509 分**（位次约 46,774）、第二批次 **484 分**，另有「**大江文化科技艺术节**」等品牌活动。
>
> **档案编写日期**：2026年10月16日　|　**数据截止**：2026年10月
> **信度标注**：`[A]` 官方发布　`[B]` 权威媒体转述　`[C]` 家长圈/自媒体口径（需交叉验证）

> ⚠️ **校名与资质核实说明**：学校规范全称为「**南京市临江高级中学**」，位于**江宁区**（秣陵街道诚信大道 188 号）。**资质以「江苏省四星级普通高中」为准**（2016 年 5 月通过省四星级现场评估验收）——部分第三方平台仍标注「三星级」，属**信息滞后**，本档案以学校官网与官方口径为准并特别说明。招生范围以**江宁区**为主。

## 二、基本情况

### 2.1 历史沿革

| 时间 | 事件 |
|---|---|
| **1956 年** | 创建，原名**江宁镇初级中学** |
| **1968 年** | 更名为**江宁县江宁中学** |
| 1996 年 | 被确定为**南京市重点中学** |
| **2000 年** | 更名为**南京市江宁中学** |
| **2007 年 7 月 / 8 月** | 学校**整体搬迁至新址**（江宁经济技术开发区诚信大道 188 号），更名为「**南京市临江高级中学**」 |
| 2008 年 | 被评为**江苏省三星级高中** |
| 2013 年 | 通过省三星级高中**复审** |
| **2016 年 5 月** | **顺利通过江苏省四星级学校现场评估验收** |
| **2020 年** | **与南京市秣陵中学合并**，沿用「南京市临江高级中学」校名 |

`[A]`

> **解读**：这是一所**有近七十年办学历史**的学校，经历了从「江宁镇初级中学」到「江宁中学」再到「临江高级中学」的**三次更名与一次整体迁址**，并完成了一次**学校合并（2020 年并入秣陵中学）**。这解释了为何该校在第一批次、第二批次均有招生数据——合并后的校区/学制结构较为复杂。
>
> **注意**：部分第三方平台（如入学网、优校网）仍将学校标注为「**三星级高中**」，这是**2016 年四星评估前**的旧信息。本档案以**学校官网明确记载的「2016 年通过省四星级现场评估验收」**为准。`[A]`

## 八、办学特色

### 8.1 「实」文化：为每位学生的厚实人生奠基

学校秉承「**实**」的核心理念，坚持「**求实、务实、踏实、扎实**」的精神，形成「**实**」的校园文化。办学目标为办「**多样办学、多元发展**」的优质高中，向「**现代化、人文化、多元化、国际化**」方向迈进。`[A/B]`

### 8.2 艺体特色办学（核心差异化）

学校**主打艺体特色**，开设**美术班、音乐班、传媒班**及**体操等运动队**，是江宁区**艺体生培养的重要基地**。`[B]`

### 8.3 科技教育特色

学校为「**江苏省青少年科技教育先进学校**」「**江苏省科技教育四星级学校**」，并建**数字化探究室**、承担**全国教育科学「十二五」规划教育部规划课题**。`[A]`

### 8.4 心理健康教育特色

学校为「**江苏省中小学心理健康教育特色学校**」，设**示范心理咨询室**，心理健康教育是其另一张名片。`[A]`

### 8.5 「大江文化」品牌活动

学校举办**第十届「大江文化科技艺术节」**，以「一眼览山河」式的校园文化展演（如「一班一城市」微缩世界旅行）形成独特品牌，是学校**「大江文化」**主题的集中呈现。`[A]`

### 8.6 地域文化：九龙湖畔的「临江」意象

校名「临江」与毗邻九龙湖的地理位置相呼应，「大江文化」系列活动的命名亦由此而来，形成鲜明的**地域文化标识**。`[A]`

## 十、择校小结

### 适合的学生画像

| 维度 | 判断 |
|---|---|
| 江宁区自住、第一批次压线考生 | ★★★★★（第一批次 509 分，区内四星最低门槛） |
| 江宁区第一批次未录取考生 | ★★★★★（第二批次 484 分，二次机会） |
| 有**美术 / 音乐 / 传媒 / 体育特长** | ★★★★★（艺体特色是核心优势） |
| 看重师资中特级教师配置 | ★★★★☆（特级 3 人，数据较透明） |
| 看重交通便利 | ★★★★☆（地铁 3 号线诚信大道站） |
| 追求高本科率 / 一本率确定性 | ★★☆☆☆（升学数据缺失，多为 C 级口径） |
| 冲 985 / C9 | ★☆☆☆☆ |

### 关键决策变量

1. **双批次招生是最突出的结构特征**：临江在**第一批次（509 分）与第二批次（484 分）**均有招生，是江宁区四星高中中**分数覆盖最宽**的一所。**第一批次未达线但过二批次线的考生，仍有进入临江的机会**。
2. **指标生线与统招线「倒挂」需注意**：江宁区四校共用**573 分指标生控制线**，而临江第一批次统招线仅 **509 分**。这意味着——**对临江而言，走统招比走指标生门槛更低**。考生应把「指标生」志愿留给更高级别学校，用统招志愿稳妥进临江。`[C]`
3. **艺体特色是最强差异化产品**：美术、音乐、传媒、体育（体操等）多元通道，历史上「每年超百名艺体生考取本科」。**有艺体特长的考生应优先考虑临江**。
4. **师资硬指标本批次较好**：**特级教师 3 人**、高级职称 85 人、硕士 50 人，在本批次学校中数据最完整、含金量可对比。
5. **升学数据缺失是最大风险**：学校**未公开 2026 年高考量化数据**，且历史数据多为第三方 C 级口径（本科率 85% 以上等）。家长需通过在校生、区教育局质量评估等渠道自行补充验证，**不宜仅凭投档线高低判断**。
6. **地理与交通是加分项**：毗邻**地铁 3 号线诚信大道站**，江宁区内通勤便利；学校实行**寄宿封闭式管理**，安全与作息有保障。
