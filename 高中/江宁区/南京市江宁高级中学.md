## 二、基本情况

### 2.1 历史与资质

学校始建于 **1934 年**，先后**六迁校址、六易校名**。`[A]`

| 时间 | 里程碑 |
|---|---|
| 1934 | 建校 |
| 1980 | 被江苏省政府确定为首批办好的**省重点中学** |
| 1992 | 通过检查验收，批准为省合格重点中学 |
| 2002 | 创建**国家级示范高中** |
| 2004 | 转评为**江苏省首批四星级普通高中** |
| 2023.12 | 获评**江苏省首批高品质科技高中建设立项学校** |

学校确立「**崇德·力行**」的校训和「立足终身发展，为学生做人、求知和创新奠基」的办学理念。`[A]`

### 2.2 校区与规模`[A]`

| 占地 | 近 **365 亩** |
| 建筑面积 | 约 **17 万多平方米** |

### 2.3 ⚠️ 2026 年招生规模：南京「巨无霸」

**这是江宁高级中学 2026 年最显著的特征**：`[A]`

| 项目 | 数据 |
|---|---|
| **两校区共扩招** | **464 人（2026 年南京扩招最多的学校）** |
| **天元东路校区** | **1,716 人**（普通生 492 + **指标生 1,148**） |
| **福宁路校区** | **336 人**（普通生 100 + **指标生 236**） |
| **两校区总招生** | **2,052 人**（突破 2,000 人大关） |
| **指标生占比** | **接近 70%** |

> **关键解读——指标生占近 70%**
>
> 这是本档案中**指标生比例最高的学校**。全市四星级高中指标生比例要求「不低于统招计划的 50%（郊县优质高中不低于 70%）」，江宁高中作为江宁区属校，按**郊县 70% 标准**执行。
>
> **实务含义**：
> - 天元东路校区 1,716 人中有 **1,148 个指标生名额**——这意味着**江宁区各初中的学生有大量机会通过指标生路径进入江宁高中**
> - 普通生（统招）名额仅 492 人，竞争激烈
> - **对江宁区初中生而言，这是一条低门槛入口**——指标生控制线（江宁区 2026 年为 573 分）远低于统招线

### 2.4 录取位次参考`[A]`

**建议全市排名 2.2 万—2.3 万名的考生**可到江宁高级中学招生办咨询。

## 三、班型与分班（核心关注点）

### 3.1 2026 年新高一四档班型`[A]`

| 班型 | 数量 | 培养目标 |
|---|---|---|
| **南大创新班** | 3—4 个 | 培养具有**冲击 C9 高校潜质**的学生 |
| **985 创新班** | 3—4 个 | 培养具有**冲刺 985 高校**梦想的学生 |
| **实验班** | 10—12 个 | 培养 **211、双一流**方向的学生 |
| **平行班** | 14—16 个 | 培养冲刺**省属重点本科**的学生 |

**福宁路校区班型构成**（校方中招咨询会口径）：`[B]`

| 班型 | 数量 |
|---|---|
| **创新班** | **2 个** |
| **实验班** | **5 个** |

> **解读**：福宁路校区 2026 年招生 336 人，班型结构相对精简——**创新班 2 个 + 实验班 5 个**，即该校区的班型以「创新班 / 实验班」为主体，与天元东路校区的四档细分形成差异。两校区**一体化管理**，教研与师资统筹。

### 3.2 ⚠️ 直接编入南大创新班的三条通道`[A]`

这是江宁高中 2026 年最值得关注的招生政策：

| 通道 |
|---|
| **特长生** |
| **签约的指标生** |
| **指标生报名中的高分段学生** |

> **校方原话**：「今年江宁高中的特长生、签约的指标生以及指标生报名中的高分段学生将**直接编入南大创新班**。所以**中考 580 分以上，尤其是 610—620 以上的中考生，一定不要错过机会，提前锁定南大创新班**。」

> **解读**：这是一条**「低分进名校班」的明确路径**。若考生通过指标生渠道进入江宁高中（控制线 573 分），且分数达到 610—620 以上，即可直接进入最高档的南大创新班。**对江宁区中上游学生，这是性价比极高的选择。**

### 3.3 创新班管理团队

**张格波**：南京市江宁高级中学党委书记，江苏省「苏教名家」培养工程培养对象，**江苏省数学特级教师**，中学正高级教师。先后获得**南京市斯霞奖**、南京市优秀青年教师、南京市学科教学带头人等荣誉称号。`[A]`

## 八、择校小结

### 适合的学生画像

| 维度 | 判断 |
|---|---|
| 江宁区初中生（走指标生） | ★★★★★（指标生近 70%，控制线 573 分） |
| 中考 610—620 分（冲南大创新班） | ★★★★★（直接编入通道明确） |
| 目标省属重点本科 / 双一流 | ★★★★★（B 类综评全省第一） |
| 追求高性价比（低分进好班） | ★★★★★ |
| 目标 C9 顶尖 | ★★★☆☆（南大创新班，3—4 个） |
| 需要高个体关注度 | ★★☆☆☆（2,000+ 人规模） |
| 江宁区自住 | ★★★★★ |

### 关键决策变量

1. **指标生是最大红利**：天元东路校区 1,148 个指标生名额，占比近 70%。江宁区指标生控制线 573 分，远低于统招线。**对江宁区初中生，这是最容易进入优质高中的通道。**
2. **「直接编入南大创新班」的政策含金量高**：通过指标生渠道进入 + 中考 610—620 以上 → 直接进最高档班型。这是明确的「低分进好班」路径。
3. **B 类综评全省第一是隐性优势**：对目标为省属重点本科（南工大、南邮、南林等）的学生，江宁高中的综评通道产出全省领先。
4. **2026 年扩招 464 人**：南京扩招最多的学校，位次门槛下移明显。
5. **规模是双刃剑**：2,052 人的招生量带来资源丰富度（课程、师资、高校合作），但个体关注度下降。适合自律性较强的学生。
6. **四大高校共建班**：利用江宁大学城优势，对已明确专业方向的学生有实际价值。
